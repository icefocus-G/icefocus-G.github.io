# 数学卡片

给小学生（成都主城区，人教版 1~6 年级）做的口算表 / 知识点 / 应用题单页应用。
跟隔壁「识字卡片」「英语卡片」是同一套骨架：`data/*.json` 是唯一数据源，`data/*.js` 是双击打开时的兜底，
改完数据不用改代码。交互、纸张、点读、翻页、导出、打印全部沿用，内容与专项交互换成数学的。

- **口算表**：A4 一页 40 题（竖版 4 列 ×10 行），按教材单元分页，也能按「计算题型」专项练
- **知识表**：149 条知识点，按单元分组排成速查表（册标签 + 单元名 + 每条一行的名称/公式/说明），点一下读出来
- **应用题**：6 个年级各 4 道，一屏全铺；题目按句拆开、逐句可点读，点「解题思路」在题目右侧展开步骤（窄屏 700px 以下才落到题下）
- **学计算**：数位表、20 以内加减表、乘法口诀表、竖式三条规矩、凑十破十演示、运算顺序、单位换算速查、易错点
- **加题**：自己写算式（自动算答案）或按范围自动出题，进来自定义题库
- **数学专属**：答题闯关（判分 / 连对 / 计时）、十格阵与数轴演示、竖式逐位点亮、错题本、速查表

---

## 快速开始

| 场景 | 怎么做 |
|---|---|
| 电脑 | 双击桌面的 **数学卡片** 快捷方式，或 `启动.bat`（本机 .html 关联坏了，所以显式调 Chrome 的 `--app` 模式） |
| 平板 / 手机 | 起个静态服务（`python -m http.server 8099`）后浏览器打开；iOS Safari「添加到主屏幕」就是独立应用，断网也能用 |
| 重新生成图标 / 快捷方式 | `python tools/make_icon.py`、`python tools/make_shortcut.py`（加 `--all` 会多建四个入口） |

`index.html` 双击也能开（`file://`），数据走 `data/*.js` 兜底，只是语音要联网。

## 五个页签

### 口算表（默认）

两套纸张：**竖版 A4**（210×297，4 列 ×10 行 = 40 题）和 **横版**（297×210，5 列 ×8 行，iPad 横屏自动用这套）。
打印 / 导出 PNG 一律按竖版，跟屏幕上正用哪套无关。

题目怎么挑（顶栏下拉）：

- **按教材单元**：12 册 / 106 单元，一单元一张纸，标题就是「一上 · 一、准备课」
- **按计算题型**：22 组（10 以内加减、表内乘法、小数乘除、分数加减、解方程、单位换算、比与比例……），一题一页 40 道
- **自定义**：加题页加进来的题

单元题不够一页（比如「准备课」只有 11 道比大小）会自动用同册其它单元的题补满，标题后面标「＋同册复习」，不会印出半张白纸。

格子里怎么排：一道题拆成「文字 / 填空线 / 比大小圆圈 / 答案」几段，按真实字宽算字号，长题自动缩字号，
「6平方分米＝＿＿平方厘米」这种过长的会从等号处折成两行。分数一律排成上下两层带横线（答案也是），
不是写成 `1/2`。解方程的答案另起一段，写成「8x=24　x=＿＿」。

**纸面字号统一由 `index.html` 里的 `PAPER_TEXT_SCALE` 控制**（当前 `0.85`，即比初版小一成半）。
它同时管屏幕、打印、300dpi 导出三处，改一个数字全部生效；只影响纸面（口算题），
顶栏按钮、知识表、应用题这类界面文字不走它。比大小的圆圈固定 0.78 个字高、底边坐在基线上，跟着字号一起缩。
注意 `splitLines()` 里「挤到 6mm 以下才折行」的阈值也乘了这个系数，按比例改就行。

### 知识表

149 条，按册挑（全部 / 一上 / 一下 / … / 六下）。**不是方格卡片，是一条条排下来的速查表**：

- 每个单元一条浅橙标题条：左边一个「一上」式的册标签，后面是单元名（如「三、1~5 的认识和加减法」）
- 每个知识点一行：**左边名称、右边公式、公式下一行说明**，行底一条细分隔线
- 按行高流式分页（A4 竖版 273mm 一页约 11 条 / 9 组，共 13 页；横版一页约 10 条）。一组排到页尾没排完时，
  下一页顶上重印组标题并标「（续）」
- 字号全页统一：公式最大 6.6mm、名称 4.5mm、说明 4mm；`knowType()` 会按这一页最长的公式 / 说明反推字号，
  保证再长的公式也不会被切掉
- `说明开 / 说明关` 只藏那行小字（`visibility`），公式和行高一个像素都不动

版面参数集中在 `index.html` 的 `KNOW_HEAD / KNOW_ITEM / KNOW_NAME_W / KNOW_NAME_FS / KNOW_EXPR_MAX / KNOW_NOTE_MAX`。
HTML 排版（`knowPageHTML`）和 300dpi 导出（`drawKnowPage`）读的是同一套数字，改完两边一起变；
导出时公式中线在行内 5.4mm、说明中线在 13mm，改行高要同步这两个值。

### 应用题

选年级 → 这个年级的 4 道题一次全铺在同一屏（不是一次只看一篇），每道题左栏是题干、
右侧是思路和答案（宽屏并排，窄屏 700px 以下才回落到题下方）：

- `解题思路`：在题目右栏展开步骤，再点一次收起；每道题各开各的，互不影响
- `看答案`：同一栏展开答句
- `朗读`：把这道题的句子从头顺着读（再点变「停止」）

右栏只在展开时存在（`.ap-sheet.split` 才显示 `.ap-side`），所以收起状态下卡片高度完全不受影响，
一屏能看全四道题。左栏固定 `flex:1 1 auto`，右栏 `min(48%,384px)`、打印时 46%。

题目逐句列出来，点一句读一句。顶部还有 `全部展开思路 / 全部展开答案`（全展开后变成「收起全部」）和
`打印本页` —— 打印走 A4 竖版，4 道题带虚线分隔、每道题下面留 11mm 空白给孩子写算式。

### 学计算

家长带读用的速查页，全部内容写死在 `index.html` 的 `renderCalc()` 里：

- 数位与读数（亿级 / 万级 / 个级，10 个位置一格）
- 20 以内加法表、20 以内减法表、乘法口诀表（三角排列 45 句）——点一格读出来
- 竖式三条规矩、凑十法 / 破十法（点例子直接开十格阵演示）、运算顺序、单位换算速查（点一行读进率）、最容易错的地方

### 加题

- **自己加题**：一行一道，支持 `+ - × ÷` 和小括号，例如 `25×4`、`3.6+1.8`、`(12+8)÷5`；边打边列出来并算好答案，重复的只算一次
- **按范围自动出题**：选题型（加减 / 乘 / 除 / 分数 / 小数…）、数的范围、几道，一次生成 40 道

## 数学专属交互

### 答题闯关（`开始练习`）

- 当前这张纸上有什么题就考什么，一题一题来，答对自动进下一题
- 键盘按答案类型自动切：普通题是数字键盘（答案里带 `.` `/` `:` `…` 时会多出对应的键），比大小题只有 `＞ ＝ ＜` 三个键
- 判分做了归一化：全角转半角、`x=` 前缀、`1/2` 与 `0.5` 之类的小数等价都算对
- 顶部有进度条、连对、计时；做完给正确率 / 做对 / 做错 / 用时，错了的自动进错题本
- 每题都能 `看演示`（有演示的题型）、`读一遍`、`跳过`

### 演示动画

| 题型 | 演示 |
|---|---|
| 20 以内进位加 / 退位减 | 十格阵：先摆几个、再添几个，凑十时把第二格的几个点**真的飞过去**填满第一格，说明文字同步变成「第一格满了：10 个」 |
| 加减、比大小 | SVG 数轴：从起点描一条弧线走到答案（`getTotalLength` 描线动画） |
| 多位数加减乘 | 竖式：逐位点亮 `data-col`，满十进一 / 不够减退一点位标出来 |
| 表内乘除 | 口诀表定位：在 9×9 三角表里找到那一格 |
| 分数加减 / 乘除 | 分数条：两条拼起来看够不够一个整条 |
| 解方程 / 比与比例 / 单位换算 / 百分数 | 一步步的等式变形、进率阶梯 |

### 错题本

答错自动收进来（同一道题只记一次），存在浏览器本地；可以 `重做一遍`（重新开一轮闯关）、`打印错题卷`（按 A4 竖版排版）、`清空`。
口算表底部的 `错题本` 按钮上有小角标，随时看还有几道没消化。

### 速查表

学计算页里的单位换算速查（长度 / 面积 / 体积 / 容积 / 质量 / 时间 / 人民币），以及应用题页的公式、运算定律、
数量关系、分数小数百分数互化，都收在 `data/tables.json`，点一行能读出来。

## 点读（声音）

点题目、点知识点卡片、点速查表一行，都会读出来（读法是构建期算好写进数据的 `s` 字段：
`7+5` → 「七加五」，`1/4` → 「四分之一」，`5%` → 「百分之五」，`x:14=2:7` → 「x比十四等于二比七」）。

- 声音是**预先生成**的 mp3（微软 edge-tts，`zh-CN-XiaoxiaoNeural`，语速 -8%），共 **3544 句**，断网也能读
- `data/audio/manifest.json` 是「句子 → 文件」绑定表，文件名取句子 md5 前 14 位、按前两位分 64 个子目录（纯 ASCII，服务器上不会乱码）
- 页面渲染完会把当前页的音频在后台取成 blob（最多留 320 条），点下去直接播，不等网络；全程复用同一个 `<audio>`（iOS 上频繁 `new Audio()` 会「点了没声音」）
- `sw.js` 对 `/data/audio/` 下的 mp3 直接放行：Safari 播 `<audio>` 会先发 `Range` 请求，Service Worker 回一个完整的 `200` 会让它判定「不支持分段」然后静默
- 顶栏 `声音开 / 声音关`，状态存本地

改了题目以后要补语音：

```bash
python tools/build-audio.py            # 增量，只补新的
python tools/build-audio.py --force    # 全部重来
python tools/build-audio.py --limit 20 # 试听用
```

需要 `pip install edge-tts`。脚本会顺带重写 `manifest.json` / `manifest.js`。

**没声音先看这几条**（地址后加 `?diag=1` 会弹出左下角自检面板，里面有「语音清单」「已预取」「最近一次播放错误」）：

1. iPad 侧边静音键（最常见），音量、耳机
2. Safari 设置 → 网站设置 → 自动播放：允许
3. 面板里点「试听一下『七加五』」，看「最近一次播放错误」：`NotAllowedError` = 手势没算进来，刷新再点；空白 = 播成功了，是设备静音

## 改内容

**加题 / 改题**：题目不是在浏览器里随机生成的，而是在 `tools/build_math.py` 里、构建时按规格展开成具体的
`{p: 题面, a: 答案, s: 读法}`，保证每次打开都一样。改完跑：

```bash
python tools/build_math.py     # 重新生成 data/*.json
node   tools/build-data.js     # 重新生成 data/*.js（file:// 兜底）
python tools/build-audio.py    # 补新句子的语音
```

- 想加一个单元 → 改 `content_books.py`，给它一个 `gen` 规格（`k` 是出题器名字，`n` 是题量，其余是范围参数）；纯概念单元不给 `gen` 就只有知识点
- 想加一种出题方式 → 在 `build_math.py` 的 `GENS` 里加一个函数，返回 `[{p, a}]`，再在 `content_text.py` 的 `TYPES` 里挂上去
- 加知识点 / 应用题 / 速查表 → 改 `content_text.py` 的 `KNOW` / `APPLY` / `TABLES`

**数据结构**（`data/books.json`）：

```json
{ "books": [ { "id":"1a", "grade":1, "name":"一年级上册",
  "units": [ { "no":"一", "title":"准备课（数一数、比多少）", "note":"谁多谁少，用一一对应比",
    "items": [ { "p":"4○1", "a":">", "s":"四和一比大小" } ] } ] } ] }
```

题面里的 `＿` 是填空线，`○` 是比大小圆圈；两者都没有的纯算式（`0+5`）前端会自动补「= 空位」。

## 地址参数

做成多个桌面快捷方式或截图时用：

```
?view=drill|know|calc|apply|add   直接打开某一页
&scope=book:1a | type:t10         按教材某一册 / 按某个计算题型
&book=2b                          知识表只看某一册
&ans=1 | ans=0                    答案直接开 / 关
&note=0                           知识点不显示那行说明
&sort=random&seed=20261107        随机顺序（同一个 seed 结果固定）
&paper=portrait|landscape         强制纸张版式
&diag=1                           弹出自检面板
```

`scope` 的值认不出来会被忽略（不会把纸面搞成空白）。

## 已知的小脾气

- **iPad 横过来**才是 5 列 ×8 行；竖着看是竖版 A4 缩小，字会小（A4 纸本来就大），练习请用 `开始练习` 那一层
- 打印永远按 A4 竖版：屏幕在横版时点 `打印本页` 会先切回竖版再调打印机
- `sw.js` 的缓存名改了要升版本号（现在是 `math-cards-v1`），否则 iPad 上会一直吃旧页面
- 教材版本是人教版（成都主城区现行）；换版本要改 `content_books.py` 的单元目录
