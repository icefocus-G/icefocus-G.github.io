# 英语卡片

给小朋友做**单词表 / 短语表 / 分级阅读**的单页应用。词库严格按**人教版《英语（新起点）》一年级起点（成都主城区现行教材）1~6 年级 12 册**编排，数据全在 `data/` 里。

它和 `M:\识字应用`（识字卡片）是同一套做法、同一套代码骨架，只是把「汉字」换成了「英语单词」：

| | 识字卡片 | 英语卡片 |
|---|---|---|
| 第一页 | 学拼音 | **学拼读**（26 字母 / 短元音 / 长元音 / 31 个字母组合 / 规则） |
| 第二页 | 识字表 | **单词表**（词 + 英式音标 + 中文） |
| 第三页 | 词组表 | **短语表**（教材短语，2/3/4 个词，逐词注音） |
| 第四页 | — | **阅读**（1~6 年级分级短文） |
| 第五页 | 加字 | **加词** |
| 挑词入口 | 按年级挑字 | **按年级挑词**（1~6 年级，教材单元顺序） |
| A4 版式 | 8 列 × 11 行 | 竖版 5 列 × 8 行 / 横版 8 列 × 5 行，都是 40 词/张（每格三行） |
| 点读 | 一个音一个 mp3 | 一个音一个 mp3，1316 条（英式女声） |

**打开方式**：线上从工具箱「英语卡片 · 教材版」进入，或访问 `https://icefocus.cn/en-card/`；本机可以双击桌面「英语卡片」快捷方式、`启动.bat`，或直接打开 `index.html`。

> 线上版在 GitHub Pages 仓库 `icefocus-G/icefocus-G.github.io` 的 `en-card/` 目录，和本机这份是同一套代码。改完记得把 `index.html`、`data/` 同步过去再提交。`icefocus.cn/yingyu` 是另一个页面（英语·专升本学习助手），别混了。

> 教材版本的说明：成都各区县并不完全统一（部分郊县用 PEP 三年级起点）。本应用按**成都主城区一年级起点的人教版新起点**编排；如果孩子用的是别的版本，把 `tools/textbook.txt` 换成对应课本的词汇表，重跑下面的生成命令即可。

## 五个页面

### 单词表

- A4 竖版 5 列 × 8 行、横版 8 列 × 5 行，都是 40 词/张，多的顺延
- 每格三行：**音标在上、单词在中、中文在下**；三行高度按字号比例算死，关掉音标或中文时单词大小、格子间距一个像素都不变
- `隐藏单词` 只藏单词和中文、**留着音标**，正好当「看音标读单词」的测验；点一下露出来并朗读
- 字号按 canvas `measureText` 的真实宽度自适应，`schoolbag` 和 `a` 都不会挤破格子
- 衬线 / 无衬线 / 手写体三种字体

### 短语表

- 教材短语按词数分三组：2 词 122 条、3 词 66 条、4 词 14 条（竖版 4/3/3 列，横版 6/5/4 列）
- 逐词注音：`play football` 的 /pleɪ/ 压在 play 上、/ˈfʊtbɔːl/ 压在 football 上
- 下面一行是整条短语的中文；点一下读**整条**
- 短语**不按词库过滤**：短语是整句记的，不该因为词库里没有某个词就丢掉

### 阅读

- 顶栏五个页签里的「阅读」，1~6 年级各 3 篇，共 18 篇原创短文
- 每篇只用**本年级及以前**学过的教材词，带逐句中文对照
- 点句子听读；`整篇朗读` 连续播放；`中文开 / 中文关` 做遮挡测验；`打印本页` 出一张干净的 A4
- 短文数据是 `data/reading.json`，源文本在 `tools/reading.txt`

### 学拼读

- 卡片只印**两行：字母 / 字母组合 + 发音**，不再显示下方例词（例词只在 `data-say` 里，点卡片才报出来）
- 26 个字母：点一下听**字母名**（A 读 /eɪ/）
- 5 个短元音、4 个长元音（魔法 e）、9 个辅音组合、22 个元音组合
- 同一个组合的两种读法都列出来：ea /iː/ tea 与 /e/ head，ow /aʊ/ cow 与 /əʊ/ snow，oo /uː/ moon 与 /ʊ/ book，er /ə/ teacher 与 /ɜː/ her，th /θ/ thin 与 /ð/ this
- 底下是拼读规则（-s / -ed 三种读法、重音、连读）和易混点（b/d、p/q、th 清浊、ship/sheep…）
- **单个音素没有录音**，所以拼读区的卡片点一下读的是示范词（底部浮层会提示是哪个词），不会再读成字母名 /eɪ/ 之类跟卡片上 /æ/ 对不上的音。内容写死在 `index.html` 的 `PH_LETTERS` / `PH_SECTIONS` / `PH_RULES` / `PH_TRAPS`

### 加词

- 打字或整段粘贴，标点 / 数字 / 中文当分隔符，重复只算一次
- 实时显示「输入 / 新增 / 已存在」，音标表里没有的词标橙，加进去只是那格空两行

## 点词就能听

| 位置 | 点一下 |
|---|---|
| 单词表 / 短语表格子 | 读这个词 / 整条短语 |
| 26 字母卡 | 读字母名 |
| 拼读区卡片 | 读示范词（不会读字母名），底部提示词 |
| 阅读页的句子 | 读这一句；`整篇朗读` 连续读 |
| 按年级挑词的卡片 | 读这个词并选中 / 取消 |

- 读的时候那一格闪一下蓝底；连点两个，后一句打断前一句
- 顶栏 `声音开 / 声音关` 一键静音（手机上缩成「声音 / 静音」）

**声音从哪来**：`data/audio/` 里是预生成的 mp3（edge-tts `en-GB-SoniaNeural`，语速 -8%），共 1316 条：

| 内容 | 条数 |
|---|---|
| 单词（含教材词、旧版自定义词、短语音标用词） | 998 |
| 教材短语 | 202 |
| 字母 A~Z（读字母名） | 26 |
| 阅读句子 | 90 |

`data/audio/manifest.json` 是「文字 → 文件」绑定表，`readings` 用 `g1a1:0` 这类键存句子：

```json
{ "words": { "cat": "d0/cat.mp3" },
  "phrases": { "play football": "2b/play-football.mp3" },
  "letters": { "A": "7f/up-a.mp3" },
  "readings": { "g1a1:0": "2a/i-have-a-book.mp3" } }
```

- 文件名只用 ASCII，字母名走 `up-a.mp3` 和单词 `a` 区分；按哈希分到 64 个子目录
- `manifest.js` 是脚本版，`file://` 双击打开时兜底
- 换音色：改 `tools/build-audio.py` 的 `VOICE`，再 `python tools/build-audio.py --force`
- 没有对应 mp3 的词退回浏览器 `en-GB` 语音合成

## 滑动、纸张版式、打印、离线

**真纸滑动**：纸不加投影，只留一条细纸边。手指 / 鼠标拖动时纸跟着走并轻微倾斜；左右划过约 46px，旧纸推出画面、新纸从另一侧滑进来；到第一页 / 最后一页继续拉，或上下拉到底，都是越拉越沉的橡皮筋阻尼，松手弹簧回弹。只在单词表、短语表生效。

**两套纸张**：

| | 竖版（打印模式） | 横版（iPad 横屏） |
|---|---|---|
| 纸张 | A4 210 × 297 mm | A4 横向 297 × 210 mm |
| 单词表 | 5 列 × 8 行 | 8 列 × 5 行 |
| 短语表 | 4 / 3 / 3 列 | 6 / 5 / 4 列 |
| 用途 | 打印、导出 300dpi PNG | iPad 横着看，字更大 |

- **iPad 打开直接是横屏版式**（靠 UA + 触控点数判断，iPadOS 伪装成 Mac 也能认出来）；顶栏按钮「打印模式 / 横屏模式」一键互换，选择记在 localStorage
- 地址后加 `?paper=portrait` 或 `?paper=landscape` 可强制，适合做成固定版式的桌面快捷方式
- **打印本页 / 打印全部 / 下载本页一律按 A4 竖版输出**，跟屏幕上当前是哪套无关；直接按 Ctrl+P 也会临时切成竖版，印完还原
- 打印时 A4、边距选「无」；阅读页有独立的 `打印本页`
- `sw.js` 缓存页面和数据，mp3 不缓存（Safari 的 Range 限制），断网时点读退回系统语音
- 本地双击打开时不注册 Service Worker，数据改完必须重跑 `build-data.js`

## 改内容的工作流

**改教材词、改中文、改阅读短文** → 改 `tools/textbook.txt` 或 `tools/reading.txt`，然后：

```bash
python tools/build_textbook.py    # 重新生成 dict / phon / levels / reading 四份 json
node   tools/build-data.js        # 生成四份 js（本地双击打开必需）
python tools/build-audio.py       # 增量补新词、新句子的语音
```

需要 `pip install edge-tts`。`build_textbook.py` 会用 `.cache/en_UK.txt` 自动补英式音标，`.cache/phon_base.json` 里手工校过的音标优先；重跑不会污染数据。

**日常只加几个词**：直接在页面「加词」里加，或改 `data/dict.json` / `data/phon.json` 后重跑 `node tools/build-data.js`。页面里加的词存在浏览器本地，不写回文件。

**从旧版本升级**：老版那套自编的 147 词默认词库会在打开时自动换成一年级教材词库；自己加过词的列表保持不动。想手动恢复，点「词库 → 恢复默认词库」。

## 已知限制

- 词表是**转录整理**而非出版社官方电子词表；个别版本差异请按课本核对
- 音标为英式 DJ 写法，词典自动补的部分已做统一（ɛ→e、ɐ→ə、ɹ→r），极个别词可能和课本注音习惯略有出入
- 单个音素（/æ/ 之类）没有独立的录音，拼读卡读的是示范词；卡面不印例词，点一下会用浮层提示
- 语音必须由用户先点一下（浏览器不允许自动出声）；iPad 侧边静音键会连网页音频一起静音
- 手机上偶尔第一次点击没声音：再点一下就好
- 数据存在浏览器 `localStorage`（键 `english_cards_v1`），换设备不会同步，用「词库 → 导出 / 导入 JSON」搬运

**iPad / iPhone 上没声音？** 地址后加 `?diag=1` 打开自检面板，点「试听一下 apple」看错误码；先确认侧边静音键和音量。

## 和识字软件的关系

**一样的**：数据装载（json + js 兜底）、mp3 预取与 blob 播放、iOS 的 `Range` 坑、拖动翻页、300dpi PNG 导出、打印、窄屏「更多」面板、localStorage、导出 / 导入。

**换掉的**：汉字 → 单词；拼音 → 音标；词语 → 短语；田字格 → 格子辅助线；`zh-CN` 语音 → `en-GB` 语音；自编分级 → 教材年级。

**加了的**：每格第三行中文及独立开关；字号按 canvas 真实宽度自适应；短语页不按词库过滤；分级阅读页。
