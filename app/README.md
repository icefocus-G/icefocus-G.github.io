# 工具箱 · iPad 应用壳

一个"壳"页面：装到 iPad 主屏后，没有 Safari 的地址栏和工具栏，打开的**就是线上工具中心**
（`https://icefocus.cn/tool/`，源码在本仓库 `tool/`）。

在线地址：**https://icefocus.cn/app/**

```
app/
├── index.html             壳：内嵌 ../tool/ 的 iframe + 启动画面 + 悬浮菜单
├── manifest.webmanifest   桌面名、图标、standalone 显示模式
├── sw.js                  只缓存壳自己（/app/），断网也能打开壳并提示
├── icon-180/192/512/1024  桌面图标（180 是 iOS 实际用的 apple-touch-icon）
├── splash/                iPad 各机型启动图，避免打开瞬间白屏
├── build-assets.py        重新生成上面这些图片
├── toolbox.mobileconfig   Web Clip 描述文件：装到 iPad 上会生成主屏图标
├── build-webclip.py       生成上面这个描述文件
└── install.html           安装引导页（下载描述文件 / 说明步骤）
```

## 装到 iPad 上

### 方式 A：描述文件（会走系统「安装」，主屏出现图标）

1. iPad 用 **Safari** 打开 **`icefocus.cn/app/install`**
2. 点「下载安装文件」，允许下载配置描述文件
3. **设置** → 顶部「已下载描述文件」（或 通用 → VPN 与设备管理）→ **安装**
4. 回主屏，出现「工具箱」图标，点开全屏

比「添加到主屏幕」多的一步是去设置里确认安装。好处是可以把同一个链接发给多台 iPad
（教室里几台设备装一次就好），图标、名字、打开的地址都固定在里面，不用一台台建书签。

> 描述文件里只有一条 `com.apple.webClip.managed`，作用是「在桌面放一个指向某个网址的图标」，
> 不申请任何权限，随时可在 设置 → 通用 → VPN 与设备管理 里删掉。
> 它是未签名描述文件，安装时会提示「未验证」，点继续即可 —— 新系统如果直接拦掉，
> 就改用下面的方式 B，效果一样。

改名字 / 地址 / 图标：编辑 `build-webclip.py` 顶部的常量，然后

```bash
python app/build-webclip.py
```

### 方式 B：添加到主屏幕（最简单）

1. iPad 打开 Safari，输入 **`icefocus.cn/app/`**
2. 点顶部的**分享**按钮 → **添加到主屏幕**
3. 名字保持「工具箱」→ 添加
4. 从主屏点开，即可全屏使用（底部没有 Safari 工具栏）

> 必须用 **Safari**。Chrome / 微信内置浏览器加不了主屏，也不支持全屏模式。

### 注意

GitHub Pages 把 `.mobileconfig` 按 `application/octet-stream` 发出，Safari 收到这个类型不会弹
安装提示。所以 `install.html` 的做法是：页面加载时先把文件 `fetch` 回来，点击时在**同步调用栈**里
用 `application/x-apple-aspen-config` 重新打包成 blob 再下载 —— 一是绕过服务器的 MIME，
二是保住用户手势（iOS 只在手势里才允许下载）。以后换托管平台、能直接设
`Content-Type: application/x-apple-aspen-config` 的话，直接给链接就行，这段可以删掉。

第一次打开时底部会出现一次「点分享 → 添加到主屏幕」的提示条，点 ✕ 后不再出现
（记在 `localStorage` 的 `toolbox.shell.hint`）。

## 壳里有什么

- **启动画面**：等内嵌页第一次加载完才淡出，不会看到半截白屏
- **安全区适配**：状态栏、刘海、底部 home 指示条都留了位，内容不会被压住
- **右下角圆形按钮**（点一下展开）：

  | 图标 | 作用 | 说明 |
  |---|---|---|
  | ↻ | 刷新 | 连点两下圆钮也等于刷新 |
  | ‹ | 后退 | 内嵌页里点进子页面后回上一层 |
  | ⌂ | 回到工具中心 | 不管逛到哪，一键回 `../tool/` |
  | ⇱ | 在浏览器打开 | 交给 Safari 打开当前页（下载类工具需要真实浏览器时用） |

  菜单 5 秒不动自动收起。

- **打不开时的兜底页**：断网、或工具中心地址变了，壳会显示「连不上工具箱 + 重新加载」，
  而不是把浏览器的 404 白页直接摊在 iPad 上。恢复网络后自动重新加载内嵌页。
- **安装提示**：没装到主屏时提醒一次怎么装。

## 改哪里

**换壳里装的东西**：`index.html` 里一行

```js
var INNER = "../tool/";
```

改完记得同步 `index.html` 里的 `<iframe src="...">`，两处都指向同一个地址
（`src` 是首屏加载，`INNER` 用于后退 / 回首页 / 校验加载结果）。

**换图标 / 启动图**：改 `build-assets.py` 里的配色或图形，然后

```bash
python app/build-assets.py
```

会重写 `icon-*.png` 和 `splash/*.png`。设计稿按 1024 渲染再缩小，边缘更干净；
iOS 自己会切圆角，所以图是**直角全幅**的，别自己加圆角。

**加机型启动图**：`build-assets.py` 里的 `SPLASHES` 加一行（宽高是 CSS 像素 × 2），
再在 `index.html` 里补一条对应的 `apple-touch-startup-image` media 查询。

## 缓存策略

- `sw.js` 作用域只有 `/app/`，**不碰 `/tool/`** —— 工具中心有新内容立刻可见，不会被旧缓存卡住
- 壳自身：导航走 network-first（保证壳能更新），断网回退缓存，所以没网也能打开壳、看到提示
- 改了壳的 CSS/JS 后要把 `sw.js` 里的 `CACHE = "toolbox-shell-v1"` 提个版本号，否则老用户可能还在旧壳里

## 为什么用 iframe，而不是直接跳转

- 直接跳 `tool/` 也能用，但那样就只是"快捷方式"，装到主屏后和浏览器书签没区别
- 用壳可以加安全区适配、启动图、打不开的兜底、返回首页这类 App 该有的东西，
  同时 `tool/` 一行代码都不用改，它继续当普通网页给电脑用

## 已知限制

- **必须联网**：壳只缓存自己，工具中心页面不缓存；断网时打开会看到「连不上工具箱」
- 壳的地址是 `/app/`，工具中心仍是 `/tool/`，两个地址都要能访问
- iPad 上 `window.open`（⇱ 按钮、卡片里"新窗口"类链接）会跳去 Safari，回不到壳里，
  回到主屏重开 App 即可
