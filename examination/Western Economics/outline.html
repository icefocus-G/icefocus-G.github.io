预备课0 · 经济学思维与读图基本功

目标：不看公式也能"读懂"任何一张经济学图形。这一章是后面 16 章的地基。

0.1 经济学到底在研究什么

一句话：研究稀缺资源如何配置。人的欲望无限，资源有限 → 必须选择 → 选择就有代价。

四个核心概念
稀缺性资源相对欲望不足，是经济学存在的前提 选择因为稀缺，必须决定"生产什么、如何生产、为谁生产" 机会成本为做这件事而放弃的最高价值的那件事（不是所有放弃之和！） 理性人在约束下追求目标最大化，对边际量做反应
两条主线
微观以价格理论为核心：消费者、厂商、市场、福利 宏观以国民收入为核心：增长、失业、通胀、政策 实证"是什么"，可证伪（如：最低工资上升 10% 会减少多少就业） 规范"应该怎样"，含价值判断（如：政府应该提高最低工资）
机会成本的三种形态（对应 PPF 形状）
  • 直线 PPF → 机会成本不变（资源可完全替代）
  • 向外凸（凹函数）PPF → 机会成本递增（现实最常见：资源专用性）
  • 向原点凹 PPF → 机会成本递减（规模经济/专用设备）

0.2 读图基本功：三条铁律

  1. 先看坐标轴：经济学图形横轴几乎总是"数量 Q / 劳动 L / 资本 K"，纵轴是"价格 P / 工资 w / 产量 Y"。中级考试中 P-Q 图与 Y-r 图是最高频的两张。
  2. 斜率 = 边际量 = 比率：需求曲线斜率 = ΔP/ΔQ；成本曲线上某点斜率 = 边际成本 MC；PPF 上某点斜率 = 边际转换率 MRT。
  3. 面积 = 总量：价格线以下、需求曲线以下的面积 = 消费者剩余；价格×产量 = 总收益；MC 曲线以下到某产量的面积 = 可变成本。

0.3 边际决策：一切最优解的通用条件

理性人的决策不比较"总量"，只比较增量。只要 MB > MC 就继续做，直到 MB = MC。

场景边际收益 MB边际成本 MC最优条件
消费者买第 n 个苹果效用 MUn价格 PMU = P（货币边际效用为 1 时）
厂商决定产量边际收益 MR边际成本 MCMR = MC
企业决定雇第 n 个工人劳动边际产品价值 VMPL工资 wVMPL = w
学生学习第 n 小时多考的分数放弃的休息边际收益 = 边际成本
最常见的犯错点 "平均成本下降 → 应该继续生产" 是错的。决策看边际：即使平均成本在下降，只要 MC > MR 就该减产。

0.4 均衡与比较静态：中级经济学的标准解题流程

  1. 确定内生变量（模型内决定的，如 P、Q）与外生变量（模型外给定的，如收入、技术、政策）。
  2. 写出均衡条件（如 Qd(P) = Qs(P)）。
  3. 解出均衡值。
  4. 比较静态：让某个外生变量变一点，看均衡往哪走 —— 这一步就是所有考试简答题的答题模板。
  5. 福利评价：消费者剩余、生产者剩余、总剩余如何变化，有无无谓损失。
"沿曲线移动" vs "曲线平移"（必考辨析） 只有该模型的内生变量（通常是自身价格）变化，才引起"点沿曲线移动"；其他任何外生变量变化，都表现为整条曲线平移。

微观 11 · 需求、供给与弹性

目标：能独立画出并解释任何一次价格变动的完整因果链；能计算四类弹性并说出政策含义。

1.1 需求：不只是"想买"

需求 = 购买欲望 + 支付能力，且是一定时期内、每一价格上愿意且能够购买的数量（一个"价格—数量"的对应关系，不是一个点）。

需求定律其他条件不变，价格↑ → 需求量↓（替代效应 + 收入效应） 吉芬商品价格↑需求量反而↑（收入效应为负且超过替代效应），极罕见 需求函数Qd = f(P, I, Pr, 偏好, 预期, 买者人数)

引起需求曲线平移的 5 个因素：收入 I相关品价格（替代品/互补品）偏好预期买者数量

供给曲线平移的 5 个因素：投入品价格技术预期卖者数量相关品价格（生产者可转产）

比较静态三步法（答题模板） ① 判断冲击打在哪条曲线上（需求还是供给）→ ② 判断平移方向（左/右）→ ③ 沿静止的那条曲线读出新均衡：价格与数量的变化。
例：收入增加（正常品）→ 需求右移 → 沿供给曲线上移 → P↑、Q↑。

1.2 弹性：把"敏感程度"量化

弹性 = 一个变量对另一个变量变化的反应程度（百分比之比，与量纲无关）。

# 需求价格弹性（通常为负，习惯取绝对值）
Ed = -(ΔQ/ΔP)·(P/Q) = -(1/斜率)·(P/Q)

# 点弹性 vs 弧弹性（中点公式）
点弹性: Ed = -(dQ/dP)·(P/Q)
弧弹性: Ed = -[(Q2-Q1)/((Q1+Q2)/2)] / [(P2-P1)/((P1+P2)/2)]

# 需求收入弹性 / 需求交叉价格弹性
Em = (ΔQ/ΔI)·(I/Q)      Em>0 正常品; Em<0 低档品; Em>1 奢侈品
Exy = (ΔQx/ΔPy)·(Py/Qx)  Exy>0 替代品; Exy<0 互补品
|Ed|类型降价 1% 时总收益图形特征
> 1富有弹性总收益上升较平坦（奢侈品、有替代品）
= 1单位弹性不变（总收益最大）直角双曲线
< 1缺乏弹性总收益下降较陡峭（必需品、无替代品）
= 0 / ∞完全无弹 / 完全有弹—垂直 / 水平

1.3 弹性的政策含义（简答高频）

① 税收负担归宿
税收负担更多落在弹性小（更缺乏替代、更难退出市场）的一方。
极端：供给完全无弹性（如土地）→ 卖方全担；需求完全有弹性 → 卖方全担。
② 谷贱伤农
农产品需求缺乏弹性 + 丰收使供给右移 → 价格大幅下跌而销量微增 → 农民总收益下降。
③ 禁毒与犯罪
毒品需求缺乏弹性 → 打击供给使价格暴涨 → 成瘾者总支出上升 → 财产犯罪可能增加。
④ 厂商定价
MR = P(1 - 1/|Ed|)。垄断者永远只在 |Ed| > 1 的区间生产，|Ed| 越大加价越低。

2. 线性需求曲线中点上方的任一点，其需求价格弹性（  ）
选 B。上半段 P 高、Q 小 → |Ed| = (1/b)(P/Q) 大 → 富有弹性。
3. 丰收导致农民收入下降（谷贱伤农）的根本原因是（  ）

微观 22 · 消费者选择

目标：用无差异曲线工具独立推导出需求曲线，并完成替代效应/收入效应分解。

2.1 从基数效用到序数效用

基数效用（马歇尔、旧）
  • 效用可计量：U = u(q₁)+u(q₂)…
  • 边际效用递减规律：连续消费同一物品，每新增一单位带来的效用递减
  • 消费者均衡：MU₁/P₁ = MU₂/P₂ = λ（每一元钱买到的边际效用相等）
  • 由此推出：MU 曲线即需求曲线（MU 递减 → 需求向下倾斜）
序数效用（希克斯、现代）
  • 效用只需排序，不需计量
  • 无差异曲线：给消费者同样满足程度的商品组合的轨迹
  • 四大特征：① 向右下倾斜 ② 互不相交 ③ 离原点越远效用越高 ④ 凸向原点（MRS 递减）
  • 均衡：MRSXY = PX/PY（相对价格 = 主观边际替代率）

2.2 由价格变化推出需求曲线

2.3 替代效应与收入效应（希克斯分解）难点

价格下降对需求量的总影响可拆为两部分：

# 希克斯分解（保持原效用水平不变的补偿）
总效应 TE   = X_C - X_A
替代效应 SE = X_B - X_A   # 价格变、效用不变 → 恒与价格反向（SE 符号永远"正常"）
收入效应 IE = X_C - X_B   # 效用变、价格比不变 → 方向取决于商品性质

正常品:  SE>0, IE>0  → TE>0  需求定律成立
低档品:  SE>0, IE<0, |IE|<|SE| → TE>0  需求定律仍成立
吉芬品:  SE>0, IE<0, |IE|>|SE| → TE<0  价格↑ 需求↑（违反需求定律）

2.4 消费者剩余与不确定性（补充）

消费者剩余 CS
愿意支付的最高价格与实际支付价格之差的总和 = 需求曲线以下、价格线以上的面积。
它是"用货币衡量的效用净收益"，也是成本-收益分析的政策依据。
风险与期望效用
期望值E(X) = Σ pᵢ xᵢ 期望效用EU = Σ pᵢ u(xᵢ)（决策依据是 EU 而非 E） 风险厌恶u 为凹函数，u(E[X]) > EU → 愿买保险 风险中性/偏好u 为线性 / 凸函数
自测 · 第 2 章
1. 无差异曲线凸向原点的原因是（  ）
选 C。MRS 递减 → 曲线斜率绝对值沿右下方向变小 → 凸向原点。
2. 吉芬商品表现为（  ）
选 B。替代效应永远与价格反向（为正），吉芬品的特殊性来自极强的负收入效应。
3. 消费者均衡条件是（  ）
选 A。主观边际替代率（愿意）= 市场交换比率（能够）。B 只在 PX=PY 时成立。

微观 33 · 生产与成本

目标：掌握生产三阶段、要素最优组合条件，以及全部成本曲线的形状与相互关系。

3.1 生产函数与边际报酬递减

# 短期：至少一种要素固定（通常资本 K̄）
Q = f(L, K̄)
TP = 总产量;  AP_L = TP/L;  MP_L = ΔTP/ΔL

# 三大关系（必考）
① MP > 0 且递增 → TP 以递增速率上升
② MP 达到最大 → TP 出现拐点
③ MP = 0     → TP 达到最大
④ MP = AP    → AP 达到最大（MP 从上往下穿过 AP 最高点）
⑤ MP < 0     → TP 绝对下降

# 边际报酬递减规律：其他要素不变，连续等量增加某要素，
# 其边际产量最终必然递减（短期规律，前提：技术水平不变）

3.2 长期：等产量线与最优要素组合

等产量线
  • 同一产量下资本与劳动的各种组合
  • 特征：向右下倾斜、不相交、凸向原点（MRTS 递减）、越远产量越高
  • MRTSLK = -ΔK/ΔL = MPL/MPK
等成本线
  • C = wL + rK，斜率 = -w/r
  • 成本最小化 / 产量最大化的切点条件：
    MRTSLK = w/r 即 MPL/w = MPK/r
  • 含义：每一元钱买到的边际产量相等

规模报酬（所有要素同比例增加 λ）：f(λL, λK) 与 λf(L,K) 比较 → 递增 / 不变 / 递减。柯布-道格拉斯 Q = ALαKβ 中，α+β > 1 递增、=1 不变、<1 递减。

3.3 成本：短期与长期

概念符号定义与关系
总固定成本TFC不随产量变（厂房、设备），短期才有
总可变成本TVC随产量变（原料、工资）
总成本TCTC = TFC + TVC
边际成本MCMC = ΔTC/ΔQ = ΔTVC/ΔQ（与 TFC 无关！）
平均总成本AC(ATC)AC = AFC + AVC，U 形
平均可变成本AVCU 形，最低点低于 AC 最低点
三个"相交"关系（必考） ① MC 从下往上穿过 AVC 的最低点；② MC 从下往上穿过 AC 的最低点；③ AC 与 AVC 之间的垂直距离 = AFC，随产量增加而不断缩小（AC 曲线始终在 AVC 上方但永不相交）。

3.4 利润最大化：MR = MC（通用法则）

# 利润函数与一阶条件
π(Q) = TR(Q) - TC(Q)
dπ/dQ = MR - MC = 0  →  MR = MC（且 MC 处于上升段，二阶条件 d²π/dQ² < 0）

# 会计利润 vs 经济利润
会计利润 = 总收益 - 显性成本
经济利润 = 总收益 - (显性成本 + 隐性成本/正常利润)
经济利润 = 0 → 只赚到"正常利润"，企业无进无出（长期均衡的标志）

1. 边际成本曲线与平均可变成本曲线相交于（  ）
选 B。边际量从下方穿过平均量时，平均量处于极值（此处是最小值）。
2. 厂商生产要素最优组合的条件是（  ）
选 D。等价于 MRTSLK = w/r：每单位货币买到的边际产量相等。
3. 经济利润为零时，厂商（  ）
选 A。经济利润已扣除隐性成本（正常利润），为 0 说明恰好赚取机会成本水平的回报。

微观 44 · 完全竞争市场

目标：掌握"P = MR = MC = min AC"这条完整的效率链条，以及短期停产与长期进出的判据。

4.1 完全竞争的四个假设与两个推论

① 大量买者与卖者单个厂商份额极小 → 是价格接受者 ② 产品同质完全替代 → 无法提价（提价销量归零） ③ 资源完全自由流动长期可自由进入退出 → 长期经济利润为 0 ④ 信息完全不存在套利与信息租金

推论 1：厂商需求曲线是水平线（在市场价格上弹性无穷大）→ P = AR = MR。
推论 2：厂商的利润最大化条件简化为 P = MC。

# 完全竞争厂商的短期决策规则（背下来）
P > AC          → 超额利润，扩大生产到 P = MC
P = AC          → 零经济利润（收支相抵点）
min AVC < P < min AC → 亏损但继续生产（可弥补部分固定成本）
P = min AVC     → 停产点（生产与不生产都亏 FC）
P < min AVC     → 立即停产

# 关键结论
厂商短期供给曲线 = MC 曲线位于 AVC 最低点以上的部分
行业短期供给曲线 = 所有厂商供给曲线的水平加总

4.2 长期均衡：自由进出抹平一切利润

行业长期供给曲线的三种形状
成本不变行业水平线（要素价格不随行业扩张而变） 成本递增行业向右上倾斜（最常见：要素价格被推高） 成本递减行业向右下倾斜（外部经济）
完全竞争的效率评价
  • 生产效率：每个厂商都在 AC 最低点生产
  • 配置效率：P = MC，最后一单位商品的社会价值 = 社会成本
  • 总剩余（CS + PS）达到最大，无谓损失为 0
  • 但：无法解决外部性、公共品、垄断、信息问题 → 需要政府
自测 · 第 4 章
1. 完全竞争厂商的短期供给曲线是（  ）
选 C。价格低于 min AVC 时厂商选择生产 0，供给曲线在这一点"截断"。
2. 完全竞争长期均衡时，厂商（  ）
选 B。自由进入把价格压到 min AC；P = MC 保证配置效率。

微观 55 · 垄断市场

目标：会画垄断均衡图、算无谓损失、解释三种价格歧视，并理解自然垄断管制的困境。

5.1 垄断的成因与基本图形

唯一卖者无相近替代品进入壁垒高 → 厂商 = 行业，需求曲线就是市场需求曲线（向右下倾斜）→ P > MR。

# 线性需求下的边际收益（必背）

C = α + βY     α 自发消费(>0),  β = MPC 边际消费倾向 (0<β<1)
MPC + MPS = 1
APC = C/Y,  APS = S/Y,   APC + APS = 1

# 两部门均衡
Y = C + I = α + βY + I  →  Y* = (α + I)/(1 − β)

# 三部门（比例税 t, 转移支付 tr）
Y = α + β(Y − tY + tr) + I + G
Y* = (α + I + G + β·tr) / [1 − β(1 − t)]

# 四部门（进口 M = m0 + γY）

LM 曲线：货币市场均衡 
实际货币供给 m = M/P
货币需求 L = kY − h·r  (k 交易动机, h 投机动机)
r = (kY − M/P)/h
  • 向右上倾斜：Y↑ → 交易需求↑ → r↑
  • 三段：凯恩斯区域（水平，流动陷阱）→ 中间区域 → 古典区域（垂直）
  • LM 右侧：货币需求 > 供给（超额货币需求）

情形财政政策效果货币政策效果原因

LM 垂直（古典）完全无效（完全挤出）完全有效货币需求对利率无弹性
IS 垂直（d = 0）最有效无效投资对利率不敏感
IS 平坦（d 大）效果小效果大利率稍升即大量挤出私人投资
挤出效应的完整链条 G↑ → Y↑ → 货币交易需求↑（L₁↑）→ 在货币供给不变时 r↑ → 私人投资 I↓ → 部分抵消扩张效果。

长期总供给 LRAS：垂直

13.2 失业

类型成因对策
摩擦性失业找工作与匹配的时间（信息不完全、流动性不足）就业信息服务、职业培训
结构性失业技能/地区与岗位不匹配；最低工资、工会造成的工资刚性再培训、产业政策、放松管制
周期性失业总需求不足（经济衰退）扩张性财政与货币政策
季节性失业行业季节性波动—

奥肯定律：失业率每高于自然失业率 1 个百分点，实际 GDP 约低于潜在 GDP 2 个百分点。

13.3 通货膨胀

成因
需求拉动"过多的货币追逐过少的商品"（AD 右移） 成本推动工资/原材料上涨（SRAS 左移），伴随产出下降 = 滞胀 结构性部门间生产率与价格刚性差异 惯性通胀预期自我实现 → 通胀有惯性
成本与危害
皮鞋成本为减少持币而频繁跑银行 菜单成本频繁改价 相对价格扭曲资源配置效率下降 税收扭曲名义收入税档爬升 财富再分配债权人受损、债务人受益（未预期通胀）

13.4 菲利普斯曲线（重点）

# 原始菲利普斯曲线（1958）
失业率 u 与货币工资增长率（后改为通胀率 π）负相关

# 附加预期的菲利普斯曲线（弗里德曼-费尔普斯）
π = π^e − β(u − u_n) + v
  π^e 预期通胀;  u_n 自然失业率;  v 供给冲击;  β > 0

# 关键推论
① 短期内（π^e 固定）：u 与 π 存在替代关系 → 短期菲利普斯曲线 SRPC 右下倾斜
② 长期中（π^e = π）：u = u_n → 长期菲利普斯曲线 LRPC 为垂直线（失业与通胀无关）
③ 扩张政策只能暂时降低失业，代价是通胀上升且预期随之上移 → SRPC 上移
④ 若强行把失业压在 u_n 以下 → 加速通胀（NAIRU 含义）

14.1 国际收支与汇率

经常账户货物、服务、初次收入（投资收益）、二次收入（经常转移） 资本与金融账户直接投资、证券投资、其他投资、储备资产 记账规则复式记账，经常账户 + 资本金融账户 = 0（含净误差与遗漏）

14.2 蒙代尔-弗莱明模型（IS*-LM*）

宏观 615 · 经济增长

目标：理解索洛模型的稳态逻辑、"储蓄率不等于增长率"以及资本的黄金律水平。

15.1 增长核算与"70 规则"

# 增长核算方程（索洛剩余）
Y = A·F(K, L)
ΔY/Y = ΔA/A + α·ΔK/K + (1−α)·ΔL/L     α = 资本收入份额
ΔA/A = 全要素生产率 TFP 增长率（索洛剩余） = 产出增长 − 要素贡献

# 70 规则：变量翻倍所需年数 ≈ 70 / 年增长率(%)
增长 2% → 35 年翻倍；增长 7% → 10 年翻倍

15.2 索洛增长模型

核心方程：人均资本积累 k̇ = s·f(k) − (n + δ)·k

s·f(k)人均储蓄 = 人均投资（实际投资线） (n+δ)k持平投资：为新增劳动力(n)与折旧(δ)配备资本所需的投资 稳态s·f(k) = (n+δ)k → k̇ = 0，此后人均产出停止增长 关键结论储蓄率只影响人均产出水平，不影响长期增长率；长期增长只能来自技术进步

15.3 索洛模型的四大比较静态结论

变化稳态人均资本 k*稳态人均产出 y*稳态消费 c*长期增长率
储蓄率 s↑↑↑先↑后↓（倒 U 形）不变
人口增长率 n↑↓↓↓总产出增长率↑，人均不变
折旧率 δ↑↓↓↓不变
技术水平 A↑↑↑↑人均增长率↑（唯一来源）
收敛假说 资本边际报酬递减 → 穷国资本稀缺、回报高 → 增长更快 → 与富国趋同。
但现实中只有"条件收敛"（相同稳态的国家才趋同），因各国储蓄率、制度、人力资本差异巨大。

15.4 内生增长理论（拓展）

AK 模型
Y = AK（资本边际产出不变，不递减）→ 储蓄率提高能永久提高增长率。关键：把"知识/人力资本"纳入广义资本。
促进增长的政策 提高储蓄与投资鼓励研发与创新人力资本投资产权与法治自由贸易控制人口过快增长

1.2 核心概念

名词解释
西方经济学（广义）除马克思政治经济学以外的西方经济学说
西方经济学（狭义）20 世纪 70 年代末或 80 年代初以来，以微观经济学和宏观经济学为基础的西方发达国家现代主流经济理论
微观经济学以单个经济单位为研究对象，通过研究单个经济单位的经济行为和相应经济变量单项数值的决定，说明价格机制如何解决社会资源的配置问题
宏观经济学以整个国民经济为研究对象，通过研究经济中各有关总量的决定及其变化，说明资源如何才能得到充分利用
稀缺性人们所拥有的经济资源的数量不足以满足人们相对较大的欲望的状态
机会成本某项资源用于一种特定用途而不得不放弃掉的其他机会所带来的成本，通常由这项资源在其他用途中所能得到的最高收入加以衡量
生产可能性曲线社会使用既定的生产资源所能生产商品的最大组合

1.3 必背结论

  1. 微观经济学与宏观经济学既有区别又有联系，区别表现在：研究对象、解决的问题、中心理论和分析方法都不相同。
  2. 稀缺性导致人们必须通过放弃一些所得或支付一些费用，才能获得更有价值的经济资源。
  3. 西方经济学的三个基本问题：1 生产什么；2 如何生产；3 为谁生产。
  4. 当不减少 A 商品生产的情况下能增加 B 商品生产，表明社会资源没有得到充分利用（在生产可能性曲线内部）。
  5. 可供使用的资源总量改变，会使社会生产可能性曲线向外移动。
  6. 资源配置方式的差异体现在三方面：1 决策结构；2 动力机制；3 信息传达。
  7. 经济模型是在一定假设前提下建立的，因此会受到假设的限制，不能将实际问题全部抽象出来。
  8. 学习西方经济学：1 坚持以马克思主义为指导思想；2 联系历史和现实动态、系统学习，从整体上而不是从局部上把握。

1.4 典型例题与详解

【简答】简述微观经济学与宏观经济学的区别与联系。
区别：微观以单个经济单位为对象，解决资源配置问题，中心理论是价格理论，分析方法是个量分析；宏观以整个国民经济为对象，解决资源利用问题，中心理论是国民收入决定理论，分析方法是总量分析。联系：二者是经济学的两个组成部分，微观是宏观的基础，宏观是微观的前提和条件，二者互相补充。
【简答】什么是机会成本？试举一例。
机会成本是指某项资源用于一种特定用途而不得不放弃掉的其他机会所带来的成本，通常由这项资源在其他用途中所能得到的最高收入加以衡量。例：某人有 10 万元，用于开店的年收益是 3 万，用于存银行的年利息是 2000 元，则开店的机会成本是 2000 元（放弃的存款利息）。

2.2 核心概念

名词解释
需求在一定时间内，其他条件不变时，消费者在不同价格上愿意并且能够购买的某种商品的数量
需求量在一定时间内，其他条件不变时，在某一价格水平上愿意并且能够购买的商品数量
需求的变动由商品价格以外的因素变动引起，反应在图上为整条需求曲线的左右移动（线的平移）
需求量的变动其他条件不变下由商品价格变动引起，反应在图上为沿需求曲线上下移动（点的移动）
需求定律在其他条件不变的情况下，商品的需求量与价格之间呈反方向变动
供给其他条件不变的前提下，商品价格和厂商在该价格水平上愿意并且能够提供商品数量之间的关系
供给定律在其他条件不变的情况下，商品的供给量与价格呈同向变化的关系
需求价格弹性 Ed需求量变动百分比 / 价格变动百分比，反映需求量对价格变动的反应敏感程度
点弹性价格变化较小时用，表示某一点的弹性
弧弹性价格变化较大时用，表示两点之间的平均弹性

2.3 必背结论

  1. 需求定律的例外：1 奢侈品（价格升，需求升）；2 吉芬商品（劣质品，价格降，需求降）；3 投机商品（股票、邮票，价格升，需求升）。
  2. 其他因素变、价格不变 → 需求变动 → 线的平移；其他因素不变、价格变 → 需求量变动 → 点的移动。
  3. 需求的主体是消费者；供给的主体是厂商。
  4. 供给不变、需求增加 → 均衡价格上升、均衡数量增加；供给不变、需求减少 → 均衡价格下降、均衡数量减少。
  5. 需求不变、供给增加 → 均衡价格下降、均衡数量增加；需求不变、供给减少 → 均衡价格上升、均衡数量减少。
  6. 点弹性 Ed = -(dQ/dP)·(P/Q)，计算取绝对值（价格与需求反方向，公式加负号才方便比较）。
  7. Ed<1 缺乏弹性 → 涨价增收（多为生活必需品）；Ed>1 富有弹性 → 降价增收（薄利多销）；Ed=1 总收益与价格变动无关。
  8. 曲线越平滑越有弹性，越陡越缺乏弹性。
  9. 交叉弹性 EXY>0 替代品；=0 无关品；<0 互补品。
  10. 收入弹性 EI<0 劣等品；0<EI<1 必需品；EI>1 奢侈品。
  11. 政府限价：定低价 → 供给减少、市场短缺；定高价 → 供给增多、需求减少、市场过剩。

2.4 典型例题与详解

【计算】假定需求函数为 Q=8-2P，求 P=3 处需求的价格弹性。
由 Q=8-2P 得 dQ/dP=-2；P=3 时 Q=8-6=2；Ed=|-2×3/2|=3。属富有弹性（Ed>1），厂商应采取降价政策以提高总收益。（提示：若 P 前面没有数字如 Q=10-P，则 dQ/dP=-1。）
【简答】简述影响需求价格弹性的因素。
1 商品的可替代性：可替代程度大 Ed 大，可替代程度小 Ed 小（矿泉水替代品多 Ed 大；救命药无替代品 Ed 小）。2 商品用途的广泛性：用途广泛 Ed 大，用途小 Ed 小（自来水多用途 Ed 大；专用零件单一用途 Ed 小）。3 商品对消费者生活的重要程度：重要程度大 Ed 小，重要程度小 Ed 大（大米刚需 Ed 小；装饰摆件非刚需 Ed 大）。4 商品消费支出在预算总支出中所占比重：比例大 Ed 大，比例小 Ed 小（买车开销大 Ed 大；纽扣开销极低 Ed 小）。5 调节需求量的时间：时间长 Ed 大，时间短 Ed 小（油价刚涨短期还得用 Ed 小；多年后换新能源车 Ed 大）。

3.2 核心概念

名词解释
效用消费者通过消费或者享受闲暇等使自己的需求、欲望等得到满足的一个度量。第一，效用具有主观性；第二，效用不是物品本身的使用价值；第三，效用作为消费者行为的一种表现，偏重心理层面的发现
总效用 TU人们从商品的消费中得到的总的满足程度
边际效用 MU消费者增加一单位某消费品的消费所带来的效用的增加量（假定其他商品消费数量不变）
边际效用递减规律在一定时间内，在其他商品消费数量保持不变的条件下，随着消费者对某种商品消费量的增加，从该商品连续增加的每一消费单位中所得到的效用增量（边际效用）是递减的
无差异曲线图形上与等产量曲线类似，表示给消费者相同满足程度的商品组合
边际替代率 MRS保持效用不变时，消费者愿意以一种商品替代另一种商品的比率
预算线在收入和商品价格既定条件下，消费者所能购买到的两种商品的各种组合；斜率 = -Px/Py
消费者剩余消费者愿意支付的价格与实际支付的价格之间的差额

3.3 必背结论

  1. MU>0 时 TU 上升；MU<0 时 TU 下降；MU=0 时 TU 达到最大值。
  2. 基数效用论下（如 1、2、3、4、5 可以加减），消费者均衡条件是"每一元钱带来的边际效用相等"。
  3. 边际效用递减规律用的是"边际"——涉及两个变量的值（消费量的增量与效用的增量）。
  4. 消费者剩余来自"愿意支付"与"实际支付"之差。
  5. 无差异曲线与预算线的切点即消费者效用最大化的均衡点。

3.4 典型例题与详解

【简答】什么是边际效用递减规律？它成立的条件是什么？
边际效用递减规律是指：在一定时间内，在其他商品消费数量保持不变的条件下，随着消费者对某种商品消费量的增加，消费者从该商品连续增加的每一消费单位中所得到的效用增量即边际效用是递减的。成立条件是：一定时间内、其他商品消费数量保持不变。
【简答】基数效用论下消费者如何实现效用最大化？
基数效用论认为效用可以计量并加总求和。消费者实现效用最大化的条件是：花在每一种商品上的最后一元钱所带来的边际效用相等，即 MU1/P1 = MU2/P2 = … = λ（货币的边际效用）。若不相等，消费者会把钱从边际效用低的商品转向边际效用高的商品，直到相等为止。

答案：B。

3. 消费者剩余是（&nbsp;&nbsp;&nbsp;&nbsp;）
答案：B。

3.6 易错点

  • TU 与 MU 不要混淆：MU=0 时 TU 最大，不是"MU 最大时 TU 最大"。
  • 边际效用递减规律的成立有前提："一定时间内"且"其他商品消费数量保持不变"——少了前提就错。
  • 基数效用论认为效用可计量加总（可加减），序数效用论只认为效用可排序——两种工具不同，但推出的需求曲线结论一致。

4.2 核心概念

名词解释
劳动投入生产的人类体力和脑力
资本资本品（包括实物资本和货币资本）的生产服务
土地一切自然资源，除狭义土地外还包括江河湖海、原始森林和未经开采的矿藏等
企业家才能将各种生产要素适当地组织起来进行生产的能力

短期至少存在一种固定要素（来不及调整数量的要素）的这一时期

边际产量递减规律短期内若生产技术水平不变，随着可变要素投入的连续增加，其边际产量迟早会出现递减的现象
等产量曲线不管劳动和资本怎么组合，最终的产量都是相同的；图形上和无差异曲线一样
边际技术替代率 MRTS_LK在保持产量不变的前提下，再增加 1 单位劳动投入所能节省下的资本量（或减少 1 单位劳动所必须补充的资本量）
等成本线在成本和要素价格既定下能买到的要素组合；wL+rK=C，斜率 = -w/r，截距分别为 C/w 和 C/r
规模报酬厂商投入的各种要素呈比例地变动时产量的变化
机会成本某项生产中所使用的全部要素移至其他生产时所能获得的最高收益
沉没成本以往发生的、但与当前决策无关的费用
经济成本厂商在生产过程中使用的所有资源的机会成本 = 显性成本 + 隐性成本
显性成本厂商通过要素市场购买要素所支付的货币
隐性成本厂商在生产中所使用的自有要素的市场价值
生产者剩余厂商出售一定数量的产品所得实际收益的金额与他所能接受的最低金额之差

4.3 必背结论

  1. 经济学中的长期和短期不是指具体时间的长短，而是指厂商能否来得及调整全部生产要素投入的时期。
  2. 短期生产函数 Q=f(L)（假定资本不变）；长期生产函数 Q=f(L,K)（L、K 都可变）。
  3. TP、AP、MP 三条短期产量曲线之间的关系：(1) 三者均呈倒 U 字形；(2) AP 与 MP 交于 AP 的最高点；(3) TP 与 MP 有共通处（MP=0 时 TP 最大）；(4) AP 单调上升时 MP 在其上方；AP 达到极大值时 MP 正好经过它；AP 单调下降时 MP 在其下方。
  4. 等产量曲线的五个基本性质：(1) 密集性；(2) 有序性；(3) 一致性；(4) 递减性；(5) 下凸性。
  5. 边际技术替代率递减规律：保持技术水平不变，随着一种要素投入量的不断增加，它对另一种要素的边际技术替代率是递减的。
  6. 最优生产要素组合条件：MRTS_LK = w/r，等价于 MP_L/w = MP_K/r；此点处等产量曲线的切线斜率与等成本线斜率相等。
  7. 规模报酬三种：递增 f(λL,λK)>λf(L,K)；不变 f(λL,λK)=λf(L,K)；递减 f(λL,λK)<λf(L,K)。
  8. 短期成本：STC=FC+VC；SAC=AFC+AVC；AFC=FC/Q；AVC=VC/Q；SMC 一勾穿三线（SAC、AVC）。
  9. 利润最大化条件：MR=MC。若 MR>MC，增加 1 单位更赚钱 → 增加产出；若 MR<MC，增加 1 单位亏钱 → 减少产出；直到 MR=MC。
  10. 厂商收益：TR=P×Q；AR=TR/Q；MR=ΔTR/ΔQ。

5.2 核心概念

名词解释
完全竞争市场现实中不存在的理想市场（通常假设农产品市场近似）；厂商没有定价权，只能被动接受市场价格
垄断市场上（或整个行业）只存在一个厂商的市场结构，也称卖方垄断
垄断竞争市场既有某些竞争特点又有某些垄断特点的市场，指一种商品有许多买卖者且卖者商品之间有一定差别，从而形成不完全竞争格局
寡头垄断市场少数厂商垄断了某一行业的市场，控制了这一行业的供给，其产量在该行业总供给中占有很大比重的市场结构
价格歧视以不同价格销售同样的产品的歧视定价策略
卡特尔寡头之间存在勾结时决定产量与价格的形式
价格领先制寡头之间不存在勾结时，由一家厂商率先定价、其余跟随的价格决定方法
非价格竞争垄断竞争中通过产品差别、产品变异、广告等手段进行的竞争

5.3 必背结论

  1. 完全竞争市场必须满足四个特征：第一，有大量的买者和卖者，单个厂商的价格既定；第二，所有厂商提供的产品完全同质；第三，厂商可以自由地进入或退出市场；第四，信息充分。
  2. 完全竞争厂商短期利润最大化条件：MR=MC；三线合一——AR=MR=P（价格线、平均收益线、边际收益线重合）。
  3. 完全竞争厂商短期盈亏：P>AC 盈利；P=AC 收支平衡；AVC<P<AC 虽亏损但可继续营业；P<AVC 停止营业。
  4. 完全竞争厂商长期均衡：MR=LMC=AR=LAC=P，经济利润=0，是厂商进入或退出行业的决策点。厂商自由进出：P 大于 E 点有利润→厂商进入→产量增加价格下跌回落 E 点；P 小于 E 点有亏损→厂商退出→产量降低价格上升回到 E 点。
  5. 完全竞争厂商的短期供给曲线即其边际成本曲线在停业点以上（P>AVC）的部分。
  6. 垄断市场的条件：第一，市场上只有唯一厂商，企业就是行业；第二，垄断企业是价格的制定者；第三，其他厂商进入极为困难或不可能。
  7. 垄断产生的基本原因是进入障碍：1 垄断资源；2 政府创造的垄断或政府特许；3 自然垄断或规模经济的需要（天然气、水、电力公司）。
  8. 垄断厂商需求曲线向右下方倾斜，AR 与需求线重合（AR=TR/Q=P）；MR 位于需求线下方，且 MR 对应 Q 的位置是 D（AR）对应点 Q 位置的 2 倍。
  9. 垄断厂商短期均衡：MR=SMC，可获得最大利润、利润为零或亏损额最小；长期中因无竞争对手通常可获得长期稳定利润。
  10. 价格歧视三级：一级——每单位按愿意支付的最高价格销售；二级——不同购买数量价格不同；三级——不同市场价格不同（地区/人群/时段）。
  11. 垄断竞争市场的条件：第一，许多卖者；第二，存在产品差别；第三，自由进入和退出。垄断竞争厂商面临向右下方倾斜但比垄断厂商平坦得多的需求曲线。
  12. 垄断竞争短期均衡 MR=SMC；长期均衡 MR=LMC=SMC 且 P=AR=LAC=SAC。
  13. 垄断竞争的非价格竞争：1 产品差别（品质、性能、设计）；2 产品变异（产品差别的进一步强化）；3 广告。
  14. 寡头垄断的基本特征：(1) 少数卖方；(2) 产品既可同质也可存在差别，厂商间同样存在激烈竞争；(3) 厂商间相互依存；(4) 市场进入困难。
  15. 寡头垄断的产量与价格决定要区分是否存在勾结：存在勾结 → 卡特尔；不存在勾结 → 价格领先制。

5.4 典型例题与详解

【简答】完全竞争厂商在 AVC<P<AC 时为何仍继续营业？
因为此时价格虽低于平均总成本（亏损），但高于平均可变成本，厂商收益在弥补全部可变成本后还有剩余可弥补部分固定成本。若停产，厂商连可变成本都收不回，还要全额承担固定成本，亏损更大。所以 AVC<P<AC 时继续营业是理性的，只有 P<AVC 时才停止营业。
【简答】垄断厂商的需求曲线与边际收益曲线有何关系？
厂商即行业，其需求曲线 D 是一条向右下方倾斜的曲线，平均收益 AR 与需求线重合（AR=TR/Q=PQ/Q=P）。边际收益 MR 位于需求线下方，也向右下方倾斜。关系：D（AR）对应点 Q 的位置是 MR 对应 Q 位置的 2 倍——即在同一价格下，MR 曲线与横轴交点的产量是需求曲线与横轴交点产量的一半。

生产要素劳动、土地、资本、企业家才能

6.3 必背结论

  1. 生产要素市场上：供给方是消费者（个人或家庭），需求方是厂商；产品市场上：供给方是厂商，需求方是消费者——两者主体相反。
  2. 生产要素需求的性质：(1) 派生需求/引致需求；(2) 联合需求；(3) 供求主体有别于产品市场。
  3. 影响生产要素需求的因素：1 生产要素的价格（工资涨→对工人需求下降）；2 市场对产品的需求及产品的价格；3 生产要素的边际生产力；4 生产技术状况（劳动密集型对劳动需求高）。
  4. 完全竞争产品市场中，价格固定，每增加一单位产品 MR=P，故 MRP=MR×MP=P×MP=VMP。
  5. 生产要素的供给来自个人或家庭，供给多少取决于机会成本：要素价格越高，供给越大（要弥补机会成本）。
  6. 劳动的需求曲线向右下方倾斜，表明劳动需求量与工资呈反方向变动；只有价格变化时表现为曲线上点的移动。
  7. 影响劳动需求的因素：1 产品价格（上升→需求曲线右移）；2 技术变化（替代→左移，互补→右移）；3 其他投入品价格（替代→左移，互补→右移）；4 厂商数量变化（进入→右移，退出→左移）。
  8. 工资率的提高对劳动供给有两种效应：替代效应（多劳动）与收入效应（少劳动）；二者相对强弱决定劳动供给曲线的特殊形状。
  9. 影响劳动供给的因素：1 人口的变化；2 工作机会的变化；3 偏好的变动；4 人力资本成本的变化。
  10. 资本包括实物资本（设备与建筑物存量）和金融资本（实物资本的货币价值形态）；厂商需要金融资本本质上是为了增加实物资本。
  11. 土地市场：正常情况下土地供给不随价格变化而变化，供给曲线垂直；地租由土地市场的供给和需求共同决定；企业每多租用 1 单位土地带来的边际收益（MRP）越来越少，所以地租越高需求量越少。

6.4 典型例题与详解

【简答】为什么劳动供给曲线会向后弯曲？
工资率的提高对劳动供给有两种效应：替代效应——工资上升增加了闲暇的机会成本，人们愿意将更多时间用于工作，减少闲暇；收入效应——随着工资提高，人们可以用减少的工作时间获得同样的收入，劳动供给反而减少。工资较低时替代效应>收入效应，供给曲线向右上方倾斜；工资提高到临界点后替代效应<收入效应，劳动者不愿意再增加工作时间，供给曲线向后弯曲。
【计算】某完全竞争厂商产品价格 P=10 元，雇佣劳动的边际产量 MP 依次为 12、10、8、6、4。若工资 W=60 元，厂商应雇佣几人？
完全竞争下厂商的劳动需求由 MRP=P×MP 决定：依次为 120、100、80、60、40。厂商雇佣到 MRP=W 为止，即 MRP=60 时对应第 4 个工人（第 5 个工人 MRP=40<60，不雇）。所以雇佣 4 人。

7.2 核心概念

名词解释
瓦尔拉斯一般均衡模型描述在一个包含多种商品和生产要素的经济体系中，所有市场如何通过价格机制达到同时均衡的状态
帕累托改进存在一个对原有资源的再配置，可在不影响他人状况的条件下改善某些人的福利
帕累托最优当且仅当所有可能的帕累托改进都不存在时，即无法通过重新配置资源来改善至少一个人的福利而不减少其他任何人福利时，经济是有效率的
福利经济学在一定的社会价值判断标准条件下，研究整个经济的资源配置与个人福利的关系，说明完全竞争模型可导致帕累托最优状态
福利经济学第一定理在一定的条件下，任何的竞争性市场均衡都是帕累托最优的
福利经济学第二定理一定的消费者偏好和生产者的技术都具有凸性时，任何帕累托有效配置都可通过竞争性市场价格及收入分配来实现
基尼系数国际上广泛应用的衡量收入或财富分配不平等程度的指标；数值介于 0 和 1 之间，0 表示完全平等，1 表示极端不平等
五等分组（十等分组）收入比例把一个国家总人口按收入换成 5 个（或 10 个）部分，拿每个部分前 20%（或 10%）的人口进行比较，看比值大小
泰尔指数衡量各个子群内部和不同子群之间不平等程度；能完美分解&quot;群体间差距&quot;和&quot;群体内部差距&quot;各自占比，政策针对性极强
洛伦兹曲线描述人口按收入（或财富）从低到高排序后，累积收入（或财富）的分布状况与人口累积百分比之间关系的图形工具

7.3 必背结论

  1. 判断经济效率最常用的标准是帕累托最优；存在帕累托改进表示当前不是最优，不存在帕累托改进表示已达到帕累托最优。
  2. 福利经济学第一定理：任何竞争性市场均衡都是帕累托最优的。
  3. 福利经济学第二定理：任何帕累托有效配置都可通过竞争性市场价格及收入分配来实现（前提是偏好与技术具有凸性）。
  4. 基尼系数公式：G = A/(A+B)，其中 A 是洛伦兹曲线与绝对平等线围成的面积，B 是其下方的面积。A 面积越大越不公平，A 越小越均等；A=0 时达到最佳公平（对角线）。
  5. 洛伦兹曲线上点的读法：如"≤5% 的人口占有社会总财富的 20%"、"≤10% 的人口占有 40%"等；剩余人口占比小说明不公平。
  6. 衡量公平都是衡量收入和财富的分配程度。

7.4 典型例题与详解

【简答】什么是帕累托最优？它与帕累托改进有何关系？
帕累托改进是指存在一个对原有资源的再配置，可在不影响他人状况的条件下改善某些人的福利。帕累托最优是指当且仅当所有可能的帕累托改进都不存在时，经济是有效率的。关系：存在帕累托改进 → 当前不是最优；不存在帕累托改进 → 已达到帕累托最优。
【应用】洛伦兹曲线上显示"≤20% 的人口占有社会总财富的 60%，剩余 70% 的人口占有 20%"，这说明什么？
说明收入分配高度不均等。少数人口（20%）占有大部分财富（60%），而多数人口（70%）只占有少量财富（20%）。此时洛伦兹曲线严重偏离绝对平等线（对角线），A 面积大，基尼系数接近 1，属于"差距悬殊"，需要再分配政策介入。

答案：B。

答案：A。

7.6 易错点

  • 帕累托最优只是"效率"标准，不是"公平"标准——它不考虑分配，可能出现高效但高度不均的结果。
  • 福利经济学第一定理需要"一定的条件"（完全竞争、无外部性、信息完全等），条件不满足时结论不成立。
  • 洛伦兹曲线本身不是基尼系数——基尼系数是 G=A/(A+B)，由洛伦兹曲线派生而来。

8.3 必背结论

  1. 物品四象限（按排他性×竞争性）：私人物品（既有排他又有竞争）、俱乐部物品（有排他无竞争）、公共资源（无排他有竞争）、公共物品（既无排他又无竞争）。
  2. 公共物品生产的市场失效：搭便车者不愿主动付费，总想让别人生产后自己免费享用，所以私人不能提供最优数量的公共物品，必须由政府出面完成此项职能。
  3. 政府提供公共物品的判断标准：只要社会总收益大于总成本，政府就可以提供公共物品，并增加税收来支付成本，增加社会福利。
  4. 公共选择规则的五种：1 一致同意规则；2 需求显示法；3 多数票规则；4 加权投票规则；5 否决投票规则。
  5. 公共资源与公共物品一样没有排他性，但公共资源有竞争性（一个人使用会减少其他人的享用）。
  6. 外部性的含义：一个经济主体的行为对另一个经济主体的福利产生了影响，但这种影响并没有获得收益或付出成本（如汽车尾气排放）。
  7. 解决外部性问题的私人方案：1 企业合并而将外部性内在化；2 科斯定理（产权明确 + 交易成本为零或低成本 → 私人协商解决有效）。
  8. 政府解决外部性的三种方式：1 命令和控制方式；2 征税和补贴（庇古税/补贴）；3 可交易的污染许可证。
  9. 可交易的污染许可证与庇古税的区别：前者固定污染的量，后者确定污染的价格；两种方式都是低成本高效率地保持环境清洁的方法。

8.4 典型例题与详解

【简答】什么是公地悲剧？其产生的根源是什么？
公地悲剧是加勒特·哈丁提出的经典寓言，用来理解公共资源的使用问题。含义：公共草场无明确产权约束，放牧收益归个人、草场损耗由所有人共担，逐利驱使牧民过度放牧，有限草场持续退化，最终所有人都失去放牧收益。根源：公地作为一项资源或财产有许多拥有者，他们中的每一个都有使用权，但没有权力阻止其他人使用，从而造成资源过度使用和枯竭。
【简答】科斯定理的内容及其适用条件是什么？
内容：只要产权是明确的，并且其交易成本为零，则无论在开始时将财产权赋予谁，市场均衡的最终结果都是有效率的。即假设利益各方可以无成本或低成本进行资源配置的协商，则私人市场就能解决外部性问题，有效配置资源。适用条件：(1) 产权明确；(2) 交易成本为零或足够低；(3) 利益各方能自由协商。任一条件不满足，科斯定理的结论不成立。

9.3 必背结论

  1. GDP 定义的六个要点（必背）：(1) 核算的时间是一年；(2) 核算的空间是一个国家或经济体的经济领土；(3) 核算的载体是产品和劳务；(4) 核算的不是中间产品而是最终产品；(5) 核算的是市场价值的总和；(6) 二手交易只计入新增的服务费用。
  2. GDP = 总收入 = 总支出。
  3. 生产法：通过各产业部门增加值加总（棉花→棉纱要去除棉花价值才是增加值）。
  4. 收入法公式：GDP = 工资 + 利息 + 利润 + 租金 + 间接税 + 企业转移支付 + 折旧。
  5. 支出法公式：GDP = C + I + G + (X-M)。
  6. 两部门经济：支出角度 Y=C+I；收入角度 Y=C+S；故 C+I=C+S，即 I=S（储蓄-投资恒等式）。
  7. 三部门经济：C+I+G=Y=C+S+T-TR，整理得 I=S+（T-TR-G），其中（T-TR-G）是政府的储蓄。
  8. 四部门经济：C+I+G+NX=C+S+T-TR，整理得 I=S+（T-TR-G）-NX，其中 NX=X-M 是国外的储蓄。
  9. 名义 GDP 既反映价格又反映数量；实际 GDP 只反映物品和劳务的数量。
  10. GDP 平减指数 =（名义 GDP／实际 GDP）×100。
  11. GDP 指标的局限性（5 条）：(1) 漏掉了在家庭中生产的物品与劳务的价值；(2) 闲暇的价值不计入；(3) 不包括对污染或其他产出的负效应的调整；(4) 非法的产出及其带来的影响；(5) 对商品数量和价格计算，商品质量的改进难以正确核算。

9.4 典型例题与详解

【计算】某国一年生产并销售 1000 斤米（10 元/斤）和 500 斤棉纱（20 元/斤），其中棉纱全部用于织布，最终布匹售价 30000 元。求 GDP。
棉纱是中间产品，不计入 GDP（其价值已包含在最终产品布匹中）。GDP = 最终产品价值之和 = 米的 1000×10 + 布匹的 30000 = 10000 + 30000 = 40000 元。
【简答】为什么二手商品交易不计入 GDP？
GDP 核算的是"一定时期内（通常一年）所生产的"最终产品和劳务。二手商品在最初生产时已经计入当年 GDP，再次转手只是产权转移，没有新的生产发生。因此只有二手交易中新增的服务费用（如中介经纪费）才计入 GDP，商品本身的价值不再重复计算。

  2. 线性消费函数：c = α + βy，其中 α 为自发消费，β 为边际消费倾向 MPC，βy 为引致消费。

  10. 资本边际效率 MEC 是一种贴现率，正好使资本物品使用期内各预期收益的现值之和等于其供给价格或重置成本。

  13. 两部门均衡国民收入：y =（α+i）/（1-β）。
  14. 三部门均衡国民收入：y =（α+i+g-βt）/（1-β）。

总需求函数以产量所表示的需求总量和价格水平之间的关系

12.3 必背结论

  1. 经济周期的特征：(1) 是经济中不可避免的现象，是经济发展过程中的一个基本规律；(2) 波动无规律也难以做出准确预测；(3) 是经济活动总体性、全局性的波动；(4) 一个完整的周期由繁荣、衰退、萧条、复苏四个阶段组成（顶峰—繁荣；扩张—衰退；紧缩—萧条；谷底—复苏）。
  2. 封闭经济条件下总需求由三部分组成：AD=C+I+G（C 消费需求、I 投资需求、G 政府需求）。
  3. 总需求曲线向下倾斜的三个原因：(一) 财富效应；(二) 利率效应；(三) 国外购买效应。
  4. 国外购买效应：当外国价格水平不变、本国价格水平下降时，本国产品相对便宜，国外会增加对本国产品的需求 → 进口减少、出口增加 → 净出口水平提高 → 总需求水平增加。
  5. 影响总需求曲线移动的因素：1 预期心理；2 国外收入和物价；3 财政和货币政策。
  6. 总需求由消费支出、投资支出、政府购买支出和净出口四部分组成；税收、政府购买和转移支付通过影响这四部分来影响总需求。
  7. 古典总供给曲线的政策含义：增加需求的政策并不能改变产量，而只能造成物价上涨甚至通货膨胀。
  8. 凯恩斯总供给曲线的政策含义：只要产量小于充分就业水平，就可以用增加需求的政策来达到充分就业。
  9. 长期中总供给曲线是位于潜在产量（充分就业）水平上的垂直线，不受价格变动影响。
  10. 总需求移动的效应：(1) 短期中引起经济中物品与服务产量的波动；(2) 长期中影响物价总水平但不影响产量；(3) 影响总需求的决策者可以潜在地减缓经济波动的严重性。
  11. 总供给移动的效应：(1) 会引起滞胀——经济停滞（衰退、产量减少）与通货膨胀（物价上升）的结合；(2) 能影响总需求的决策者可以潜在地减缓对产量的不利影响，但只能以加剧通货膨胀问题为代价。

12.4 典型例题与详解

【简答】总需求曲线为什么向右下方倾斜？
第一，财富效应：价格水平较高时，公众持有的金融资产的实际价值或购买力降低（尤其存款或债券等货币价值固定的资产），公众实际上变穷了，就会减少支出。第二，利率效应：在名义货币供应量一定时，价格水平上升使实际货币供应量下降，货币需求大于货币供给，使货币的使用价格即利率上升，从而抑制投资。第三，国外购买效应：本国价格水平下降后，本国产品相对外国产品更便宜，国外会增加对本国产品的需求，进口减少、出口增加，净出口提高，总需求增加。
【简答】短期总供给曲线为什么分为向右上方倾斜和垂直两个部分？
一部分向右上方倾斜，表示总供给随物价水平上升而上升（厂商在价格上升、成本相对刚性时愿意增加产量）。另一部分向上垂直，表示总供给要受经济中资源和其他因素的制约，不可能随物价上升而无限增加——当资源已被充分利用，再提高价格也无法增加产量。

名词解释
失业有劳动能力的处于法定劳动年龄阶段的并有就业愿望的劳动者失去或没有得到有报酬的工作岗位的社会现象
失业率劳动力中没有工作而又在寻找工作的人所占的比例；失业率=失业人数/劳动人口数
自然失业经济社会正常时期存在的失业，又称长期均衡失业；是不可避免也是必要的
自然失业率在一个给定的一般均衡的经济结构中，不断重复出现的具有收敛点的失业率，既不会造成通货膨胀也不会导致通货紧缩的状态
摩擦性失业在劳动力正常流动过程中所产生的失业；不可避免
结构性失业在经济发展过程中，劳动力供给结构不能适应劳动力需求结构变化的要求而存在的失业（如 AI 相关岗位空缺，没有 AI 技能的人无法就业）
周期性失业由于整个社会对商品和劳务的有效需求不足，从而引起对劳动力的需求不足，而劳动力供给在短期内不变，出现劳动力供过于求的失业；由经济活动周期性波动引起
奥肯定律失业率每高于自然失业率 1 个百分点，实际 GDP 将低于潜在 GDP 2 个百分点；或相对于潜在 GDP，实际 GDP 每下降 2 个百分点，实际失业率就比自然失业率上升 1 个百分点
通货膨胀在纸币流通制度下，在一定时期内，由于货币发行量超过流通中实际货币需求量而引起的商品和劳务价格的普遍持续性的上涨
GDP 折算指数宏观经济学中涉及的价格指数之一
CPI（消费价格指数）告诉人们对普通家庭的支出来说，购买具有代表性的一组商品在不同时期的花费具有多少差别
PPI（生产者价格指数）衡量生产原料和中间投入品等价格平均水平的价格指数，是对给定一组商品的成本的度量
通货膨胀率从一个时期到另一个时期价格水平变动的百分比
菲利普斯曲线为政策选择提供依据：是以高通货膨胀率为代价换取低失业率，还是以高失业率为代价换取低通货膨胀率

13.3 必背结论

  1. 失业率 = 失业人数 / 劳动人口数；经济好失业率低，经济差失业率高。
  2. 失业的类型：1 自然失业（不可避免，长期均衡失业）；2 摩擦性失业（不可避免，劳动力正常流动中产生）；3 结构性失业（供给结构不适应需求结构）；4 周期性失业（有效需求不足，由经济周期波动引起）。
  3. 奥肯定律：失业率每高于自然失业率 1 个百分点，实际 GDP 将低于潜在 GDP 2 个百分点。
  4. 失业的代价：1 产量损失（用奥肯定律估计）；2 社会损失；3 对分配的影响（谁来承担失业损失，如失业者领的失业金来源于未失业的人）。
  5. 降低失业的措施：1 劳动供给方面的措施；2 劳动需求方面的措施。
  6. 通货膨胀按程度分类：年通胀率<10% 温和的通货膨胀；10%-100% 奔腾或急剧的通货膨胀；>100% 恶性或超级的通货膨胀。
  7. 按持续时间分类：一次性通货膨胀；持续性通货膨胀。
  8. 按预期程度分类：预期到的通货膨胀（物价上升程度在预料之中）；未预期到的通货膨胀（在预料之外）。
  9. 按表现形式分类：显性的通货膨胀；隐性的通货膨胀（政府进行调控）。
  10. 通货膨胀的衡量：GDP 折算指数、CPI、PPI；通货膨胀率 =（Pt - Pt-1）/Pt-1 ×100%。
  11. 通货膨胀的成因：1 作为货币现象的通货膨胀（货币数量论：每一次通货膨胀背后都有货币供给的迅速增长，M×V=P×Y）；2 需求拉动的通货膨胀（超额需求，"太多的货币追逐太少的商品"）；3 成本推动的通货膨胀（无超额需求下由生产成本提高引起）；4 结构性的通货膨胀（由经济结构因素变动引起）。
  12. 需求拉动型通胀机理：Yf（潜在产出/充分就业产出）处全社会资源已充分利用，再增加总需求产量不再增加，只有价格变化。
  13. 通货膨胀对经济的影响：(一) 影响财富和收入再分配——不利于债权人而有利于债务人；不利于固定收入者（企业受益，工人工资购买力减少）。(二) 造成经济效率的损失——增加了持有现金的成本；价格信号扭曲不利于经济活动。
  14. 通货膨胀治理措施：(一) 紧缩性的需求管理政策（紧缩性财政和货币政策）；(二) 收入政策（降低工资、其他收入和物价增长速度，工资-物价控制或道德说服）；(三) 指数化政策（货币支付与某一指数相联系，使实际购买力不受损失）。
  15. 通货膨胀的持续：不是价格水平的一次性改变，而是价格水平的持续上升；大多数情况下通货膨胀似乎有一种惯性。
  16. 菲利普斯曲线：为政策选择提供依据——是以高通货膨胀率为代价换取低失业率，还是以高失业率为代价换取低通货膨胀率；曲线上不同失业率与通货膨胀率的组合点为决策者提供不同的政策选择。

13.4 典型例题与详解

【计算】某国自然失业率为 5%，实际失业率为 7%，潜在 GDP 为 1000 亿元。用奥肯定律估计实际 GDP。
奥肯定律：失业率每高于自然失业率 1 个百分点，实际 GDP 将低于潜在 GDP 2 个百分点。实际失业率高出 7%-5%=2 个百分点，故实际 GDP 低于潜在 GDP 2×2=4 个百分点。实际 GDP = 1000×（1-4%）= 960（亿元）。
【简答】通货膨胀对收入和财富分配有何影响？
（一）影响财富和收入再分配：1 通货膨胀不利于债权人而有利于债务人——债务人偿还的是购买力已下降的货币。2 通货膨胀不利于固定收入者——企业受益，靠固定工资的工人实际购买力减少。（二）造成经济效率的损失：1 增加了持有现金的成本；2 价格信号扭曲，不利于经济活动。

14.3 必背结论

  1. 财政赤字的弥补方式：最根本的是开源节流（征税和削减支出）；另一种是借债，分为内债（国家内部发行债券）和外债（向其他国家借钱）。
  2. 财政政策的类型：(1) 公共支出政策和税收政策；(2) 扩张性财政政策和紧缩性财政政策；(3) 自动稳定器和斟酌使用的财政政策。
  3. 扩张性财政政策措施：增加国债、降低税率、提高政府购买和转移支付；紧缩性则相反。
  4. 财政预算平衡与保持宏观经济稳定之间是内在冲突的，若不可兼得需选择哪一个作为关注目标。
  5. 财政政策时机选择：在萧条状况下更多采用财政政策刺激需求，而在繁荣阶段则较少运用财政政策来遏制经济过热。
  6. 财政政策效果更好的情形：从产品市场来看，在边际消费倾向较小、税率较大、投资对利率不够敏感的情况下，财政政策效果更好。
  7. 挤出效应：政府的财政购买将通过利率上升，挤出一部分原本可能发生的投资。挤出效应是财政政策最明显的局限性之一；在挤出效应较小的情况下才认为财政政策的实施是恰当的。
  8. 斟酌使用财政政策的副作用：经济高涨时即使公共产品或服务没有显著变化，其规模仍会因紧缩财政的需要而减少供应；经济低迷时则会因扩张性财政政策而系统提高公共服务和产品的规模。
  9. 中央银行的三大职能：（一）发行的银行（控制货币印刷和发行）；（二）国家的银行（国家资金的存放与划拨）；（三）银行的银行（要求商业银行缴存法定准备金）。
  10. 货币创造：A 企业将 100 万元存入甲银行 → 甲银行保留 10% 法定准备金 10 万，其余 90 万借给 B 企业 → B 支付 C → C 存入乙银行 90 万 → 保留 9 万准备金，其余 81 万借出……
  11. 货币创造公式：存款增加总额 = 100 + 100(1-10%) + 100(1-10%)² + … = 100/[1-(1-10%)] = 1000（万元）。快速算法：最初的 100 万 / 存款准备金率 = 最终的存款增加总额。
  12. 货币政策工具：（一）调整法定准备金率；（二）调整再贷款率（商业银行缺钱向央行贷款）、再贴现率（商业银行找银行贴现）；（三）公开市场业务（央行买债券=宽松的货币政策，卖债券=紧缩的货币政策）；（四）其他（影响银行间同业拆借利率、对存贷款利率进行管制）。
  13. 货币政策的局限性：从识别出需要采取政策到最终政策效果完全呈现具有一定的时滞；在政策实施时机和时滞长度方面的判断失误可能不仅不能熨平周期性波动，甚至可能导致波动的加剧。

存款增加总额 = 100 + 100(1-10%) + 100(1-10%)² + 100(1-10%)³ + … = 100/[1-(1-10%)] = 100/0.1 = 1000（万元）。快速算法：最初的 100 万 / 存款准备金率 = 100/0.1 = 1000 万元。
【简答】什么是自动稳定器？它如何发挥作用？
自动稳定器是指经济系统本身存在的一种会减少各种干扰对国民收入冲击的机制，能够在经济繁荣时期自动抑制通胀、在经济衰退时期自动减轻萧条，无须政府采取任何行动。作用机理：经济繁荣时收入上升，累进税自动多征、失业救济等转移支付自动减少，抑制总需求过热；经济衰退时收入下降，累进税自动少征、失业救济等转移支付自动增加，减轻需求萎缩。

15.3 必背结论

  1. 宏观政策的目的：1 物价稳定；2 充分就业；3 经济增长；4 国际收支平衡。
  2. 主张自由贸易的理论在国际贸易理论中居于主体地位，经历了亚当·斯密的绝对比较优势理论、大卫·李嘉图的相对比较优势理论、赫克歇尔和俄林的要素禀赋理论。
  3. 要素禀赋理论的逻辑链：甲国出口 A 产品到乙国 → A 产品在甲国价格更低 → 价格取决于供求，需求假定相同，差异在供给 → 供给方面假定技术工艺相同，区别仅在要素投入 → 要素投入只有资本和劳动，区别在于二者价格不同 → 要素价格不同源于天然禀赋不同（资本多则资本便宜，人口多则劳动便宜）。
  4. 保护贸易政策：1 关税；2 配额；3 技术壁垒；4 财政补贴政策（目的在于促进出口而非限制进口）。
  5. 世界贸易组织和广泛存在、彼此重叠的区域贸易一体化组织，极大推动了国际贸易发展，促进了不同地区之间商品、生产要素的自由流动，推动了地区之间的政策协调和争端解决。
  6. 国际收支平衡为其中自主账户的收支相等；通常所指的国际收支平衡是指包括经常账户和资本账户在内的自主性项目借贷双方保持相等，也体现了官方储备项目的稳定。
  7. 汇率由外汇供给和外汇需求决定。
  8. 汇率管理体制三种：固定汇率制（钉住汇率制）、浮动汇率制（完全放任自由浮动）、有管理的浮动汇率制（介于其间）。
  9. 开放经济下的宏观经济均衡不仅要求产品市场、货币市场、劳动力市场上达到供求均衡，也要求外汇市场上保持平衡；宏观调控目标变成总供给和总需求相等、物价稳定、充分就业、国际收支平衡四个方面。
  10. 固定汇率制下：在资本完全自由流动的情况下，货币政策将变得完全失效；与之相反，财政政策会获得货币政策的自动配合而变得更加有效。固定汇率制和货币政策自主性之间具有一种两者只能选择其一的冲突。
  11. 浮动汇率制下：与固定汇率制相反，货币政策非常有效，而财政政策完全失效。
  12. 结论：财政政策和货币政策不可以像在封闭经济下一样都非常有效，而会出现某一方的失效，政府在调控宏观经济均衡时将会受到更大程度的制约。

15.4 典型例题与详解

【简答】简述要素禀赋理论的基本逻辑。
如果甲国能出口 A 产品到乙国，直观地理解就是这种产品在甲国价格更低、乙国价格更高，商人可以便宜地从甲国进货卖到乙国谋取价差。为什么 A 产品在甲国更便宜？从经济学看价格取决于供给和需求，对于赫克歇尔-俄林理论而言，假定两国需求完全一样，从而价格差异主要在供给方面。供给方面又假定两国生产技术、工艺完全一样，区别仅仅在于生产要素投入不同；同时假定生产要素投入仅仅区分为资本和劳动，则差异仅仅在于资本和劳动的价格不同。资本和劳动的价格为何在两国不同？因为天然禀赋不同：如果一国资本多，那么资本就便宜一些；如果一国人口多，那么劳动就便宜一些。
【简答】比较固定汇率制与浮动汇率制下财政政策和货币政策的有效性。
固定汇率制下：在资本完全自由流动的情况下，货币政策将变得完全失效；财政政策则因会获得货币政策的自动配合而变得更加有效。固定汇率制和货币政策自主性之间存在两者只能选择其一的冲突。浮动汇率制下：与固定汇率制相反，货币政策非常有效，而财政政策完全失效。总体结论是：财政政策和货币政策不可以像在封闭经济下一样都非常有效，而会出现某一方的失效，政府在调控宏观经济均衡时将会受到更大程度的制约。

  • 直接标价法"每单位外币值多少本币"——本币升值时数字变小，别搞反。
