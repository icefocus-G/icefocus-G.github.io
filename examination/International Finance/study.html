① 云端数据文件

页面与数据文件都在同一个 GitHub Pages 仓库里，读取不需要任何配置。

② 只需要做这一次：粘贴 Token

Token 只存在你这台设备的浏览器里，不会上传、不会出现在网页里。
填好之后，你在任何设备上的任何操作都会自动同步，永远不用再点「同步」。
生成页面已自动勾好 repo 权限、填好名称，你只要点最下面的绿色按钮，复制那串字符贴到上面即可。

③ 自动同步

默认上传时机只有三处：① 选择题选定了答案；② 其它题型确定了「答对 / 答错」； ③ 交卷 / 重做 / 标记掌握。滚动位置、阅读时长、展开折叠、切页签只写本机，不会触发上传； 大纲页只在切换章节时记录一次位置。

说明

· 数据以 GitHub 上的 data/IF00076-sync.json 为准，手机 / 平板 / 电脑 / APK 共用同一份。
· 答案选定并完成判分后立即触发同步；折叠、滚动、笔记、自评等改动约 1 秒后上传。
· 第一次在新设备的浏览器打开时，以云端数据为准（避免空状态覆盖云端）。
· 每个浏览器只需粘贴一次 Token；Token 只存本机，绝不上传。
· 没填 Token 也能只读：点「记录 → 导出数据文件」下载 JSON，再手工传到 GitHub 覆盖。
