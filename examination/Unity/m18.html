YooAsset 资源管理 - 大游戏

可寻址资源与热更新管线

C#
// YooAsset：构建补丁清单（哈希比对生成增量包）
var local = new Dictionary<string, (string hash, int size)>
{
    ["ui/login.prefab"] = ("a1b2", 2048),
    ["ui/main.prefab"] = ("c3d4", 4096),
    ["audio/bgm.ogg"] = ("e5f6", 1048576),
    ["scene/battle.unity"] = ("1122", 524288)
};

var remote = new Dictionary<string, (string hash, int size)>
{
    ["ui/login.prefab"] = ("a1b2", 2048),          // 没变
    ["ui/main.prefab"] = ("9988", 4608),           // 改了
    ["audio/bgm.ogg"] = ("e5f6", 1048576),         // 没变
    ["scene/battle.unity"] = ("1122", 524288),     // 没变
    ["scene/boss.unity"] = ("3344", 655360),       // 新增
    ["ui/shop.prefab"] = ("5566", 3072)            // 新增
};

var add = remote.Keys.Where(k => !local.ContainsKey(k)).ToList();
var update = remote.Keys.Where(k => local.ContainsKey(k) && local[k].hash != remote[k].hash).ToList();
var del = local.Keys.Where(k => !remote.ContainsKey(k)).ToList();
var keep = remote.Keys.Except(add).Except(update).ToList();

int Sum(IEnumerable<string> ks) => ks.Sum(k => remote.TryGetValue(k, out var v) ? v.size : 0);

Console.WriteLine($"总资源 {remote.Count} 个，清单比对结果：");
Console.WriteLine($"  新增 {add.Count,2} 个：{string.Join(", ", add)}");
Console.WriteLine($"  变更 {update.Count,2} 个：{string.Join(", ", update)}");
Console.WriteLine($"  删除 {del.Count,2} 个：{(del.Count == 0 ? "无" : string.Join(", ", del))}");
Console.WriteLine($"  未变 {keep.Count,2} 个");
Console.WriteLine();
Console.WriteLine($"本次需下载 {Sum(add) + Sum(update)} 字节（{((Sum(add) + Sum(update)) / 1024.0):F1} KB）");
Console.WriteLine($"全量包需下载 {Sum(remote.Keys)} 字节（{(Sum(remote.Keys) / 1024.0):F1} KB）");
Console.WriteLine();
Console.WriteLine("结论：增量包只传「哈希变了」的文件，这就是热更省流量的核心；");
Console.WriteLine("      清单文件本身也要带版本号，否则客户端不知道去哪拿新清单。");

YooAsset 解决什么问题

Resources 目录不可热更、不能按需卸载；AssetBundle 原生 API 又要自己管依赖、引用计数、版本号、下载队列。YooAsset 把这一整套收口成「资源包 + 清单 + 下载器」三层，你只面对「加载」和「更新」两个动作，适合包体大、要长期热更的项目。

模块职责
资源收集按规则把资源划进 Bundle（按目录 / 按标签 / 单文件）
构建管线打 Bundle、生成清单、计算哈希、输出补丁包
运行模式Editor 模拟 / 单机内置 / 联机联机热更
下载器并发下载、断点续传、失败重试、进度回调

启动六步

// 1) 创建 Package
var package = YooAssets.CreatePackage("DefaultPackage");

// 2) 初始化参数（运行模式决定资源从哪来）
var initParams = new EditorSimulateModeParameters { SimulateManifestFilePath = EditorSimulateModeHelper.SimulateBuild("DefaultPackage") };
// 联机模式用 HostPlayModeParameters，需指定远端地址与内置地址

var initOp = package.InitializeAsync(initParams);
await initOp.ToUniTask();

// 3) 请求版本（拿到最新清单的版本号）
var versionOp = package.UpdatePackageVersionAsync();
await versionOp.ToUniTask();

// 4) 更新清单
var manifestOp = package.UpdatePackageManifestAsync(versionOp.PackageVersion);
await manifestOp.ToUniTask();

// 5) 创建下载器并下载（只在需要热更时）
var downloader = package.CreateResourceDownloader(10, 3);
if (downloader.TotalDownloadCount > 0)
{
    downloader.DownloadProgressChanged += (total, current) => { /* 进度条 */ };
    downloader.BeginDownload();
    await downloader.ToUniTask();
}

// 6) 正常加载
var handle = package.LoadAssetAsync<GameObject>("Assets/Res/UI/Login.prefab");
await handle.ToUniTask();
var prefab = handle.AssetObject as GameObject;
// 用完必须释放
handle.Release();

五个关键坑

  • 资源收集规则：把经常一起用的资源放同一个 Bundle，否则一个界面加载会拉起十几个包。
  • 清单版本号：远端清单和本地清单版本不一致时必须先更新清单再加载，否则哈希对不上。
  • 句柄不释放：Release() 才是引用计数减一，忘记释放内存只涨不降。
  • 异步加载的 Task 泄漏：用 await handle.ToUniTask() 时要带 CancellationToken。
  • 主包内置资源：首屏必须能打开的资源要放内置（StreamingAssets），否则没网就进不去游戏。
