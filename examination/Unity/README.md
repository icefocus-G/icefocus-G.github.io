## 怎么打开

**方式一（推荐，能真实跑 C#）**

双击 `start.command`。它会启动本地服务并自动打开 <http://localhost:7788/>。

**方式二（只浏览）**

直接双击 `index.html`，或用任意静态服务器打开。
此方式下「真实运行」按钮会提示连不上运行服务，其余功能（目录、搜索、交互演示、图片放大、复制代码）全部可用。

## 页面上能做什么

- **左侧目录**：本篇 h2~h5 自动生成，滚动高亮；下方是 27 个模块的快捷切换。
- **代码块**：语法高亮、一键复制、超长自动折叠（可展开）。
- **本模块可运行验证**：每篇顶部有一段纯 C# 代码，点「真实运行」由本机 dotnet 编译执行，输出显示在代码下方。
- **交互演示**：每个模块一个，可点、可拖、可拖动滑块看数值变化。
- **配图**：点击放大，Esc 关闭。
- **结构图（40 张）**：思维导图、流程图、坐标系、曲线、对比表格不再是图片，而是在原位渲染成可操作的图形：
  - 思维导图 / 流程图：节点可拖、画布可平移、滚轮缩放、分支可折叠，还能一键「只留二级」「适应窗口」
  - 向量图：拖端点实时算模长、点乘、夹角、叉乘左右关系
  - 三角曲线：拖振幅 / 角频率 / 相位滑杆实时重绘
  - 三维坐标轴：按住拖动旋转视角
  - 对比表格：鼠标划过行列联动高亮
  - 每张图右上角「看原图」可随时切回语雀原图对照
- **截图文字还原（247 张）**：其余截图不再只是一张图，先做 OCR（macOS Vision，中英文），再按版面重建：
  - **Inspector 参数面板**：识别成「标签 + 数值」的表格，带分组标题，可搜索、点行复制
  - **Hierarchy / 菜单 / Project 面板**：按缩进还原成层级列表
  - **代码截图**：按等宽字体还原
  - **并排面板**（左边 Hierarchy 右边 Inspector）：按竖向空白自动切栏，两栏分别重建
  - 顶部搜索框支持实时过滤并高亮命中项
- **公式（11 条）**：原稿里的公式是 `cdn.nlark.com/yuque/__latex/<hash>.svg`（MathJax 排版好的图）。
  这里从 SVG 字形码位反推出 LaTeX，再用 HTML/CSS 排出真公式 —— 分数线、根号上横线、上下标都是真的元素，
  可以选中、可以复制，缩放不糊。像 `q = (cos45°, sin45°, 0, 0)` 这类也能逐字读出来。
- **画面语义重绘（22 张）**：3D 场景、碰撞器范围、物理效应器、UI 控件、六边形铺排这类截图，OCR 只能刮到零散单词。
  改按「这张画面在讲什么」用图元（矩形 / 圆 / 多边形 / 弧 / 箭头 / 文字）重画一遍，标注出关键量和结论。
- **保留原图（3 张）**：纯角色美术（换装素材），画面里既没有文字也没有可结构化的关系，保持原图并补一行图注。
