C#
// UniTask：串行等待与并行等待的耗时差异
using System.Diagnostics;

void Load(string name, int ms)
{
    Thread.Sleep(ms);
    Console.WriteLine($"  完成 {name} ({ms}ms)");
}

var sw = Stopwatch.StartNew();
Console.WriteLine("串行：一个等完再等下一个");
Load("配置表", 200);
Load("图集", 300);
Load("场景", 250);
sw.Stop();
Console.WriteLine($"串行总耗时 {sw.ElapsedMilliseconds}ms");

Console.WriteLine();
sw.Restart();
Console.WriteLine("并行：同时发起，等最慢的那个");
var t1 = Task.Run(() => Load("配置表", 200));
var t2 = Task.Run(() => Load("图集", 300));
var t3 = Task.Run(() => Load("场景", 250));
Task.WaitAll(t1, t2, t3);
sw.Stop();
Console.WriteLine($"并行总耗时 {sw.ElapsedMilliseconds}ms");
Console.WriteLine();
Console.WriteLine("结论：无依赖的加载一律并行。Unity 里换 UniTask.WhenAll，语义相同但不产生 GC 分配。");

替换说明2：协程（StartCoroutine）→ UniTask。原因：协程不可 await、不可 try/catch、产生 GC，UniTask 用 async/await 写法更现代、零 GC。

异步语法库（UniTask），解决的是：需要等待某件事完成（加载、动画、点击、网络），但不能把游戏卡死，同时避免丑陋的回调嵌套

🛠 用途：Unity 新一代 UI（USS/UXML，类 CSS 写法）——编辑器工具 UI 与未来游戏 UI 的官方方向。

  • ✅最显眼用途：过场加载、切换关卡（你印象中的）
  • ✅隐藏用途：游戏对局内等待动画、等待玩家点击按钮、短延时流程

为什么不用原生 Task

原生 Task 基于线程池，await 恢复时默认回到线程池线程而不是 Unity 主线程，回来操作 Transform 就直接崩。UniTask 把「等待」挂到 Unity 的 PlayerLoop 上，全程不离开主线程，也不产生 Task 的分配开销。

对比项TaskUniTask
恢复线程线程池Unity 主线程（PlayerLoop）
每帧开销分配 Task + 上下文切换值类型，0 GC
与协程互操作需要自己桥接原生支持 ToUniTask / ToCoroutine
取消CancellationTokenCancellationToken，且能随 GameObject 销毁自动取消

最常用的几组 API

// 1) 等一帧 / 等固定帧
await UniTask.Yield();
await UniTask.DelayFrame(3);

// 2) 等时间（受 timeScale 影响，UniTask.Delay 不受影响）
await UniTask.Delay(TimeSpan.FromSeconds(0.5), ignoreTimeScale: false);

// 3) 等条件成立
await UniTask.WaitUntil(() => player.hp <= 0);

// 4) 并行等待
await UniTask.WhenAll(LoadA(), LoadB(), LoadC());

// 5) 谁先完成用谁
var (idx, _) = await UniTask.WhenAny(LoadA(), LoadB());

// 6) 绑定生命周期，物体销毁就自动取消
await LoadAsync(destroyCancellationToken);

// 7) 把协程包成 UniTask
await someCoroutine.ToUniTask();

四个必踩的坑

  • 忘了 CancellationToken：物体已销毁、await 还在继续，回来访问已释放对象。
  • async void：异常会被吞掉且无法等待，除事件回调外一律用 async UniTaskVoid 并显式 Forget。
  • 在非主线程 await 后改 UI：UniTask 保证主线程，但你自己 Task.Run 里的代码仍在后台线程。
  • UniTask.Delay 与 timeScale：暂停游戏时若还想让计时器走，必须 ignoreTimeScale: true。
