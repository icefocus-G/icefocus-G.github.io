学习路线 · 原稿《学习目录》

语雀原稿首页那份 10 阶段路线图，原文照录；每阶段下面的条目按原稿顺序排列。

🏆 第一阶段：C# 语言基础（编程基本功）
打好地基，才能盖高楼！这一阶段让你拥有“写任何逻辑”的底气。
  • 💻 1.1 C# 入门 → 🎯 学会变量、循环、条件判断，能看懂基础代码逻辑。
  • 💻 1.2 C# 基础 → 🧱 掌握数组、方法、类与结构体，能封装简单的数据模型。
  • 💻 1.3 C# 核心 → ⚡ 深入面向对象（继承、多态、接口），能设计灵活的武器/技能系统。
  • 💻 1.4 C# 进阶 → 🚀 掌握委托、事件、泛型、反射、特性，能实现解耦的消息中心和插件式功能。
🕹️ 第二阶段：Unity 引擎核心（游戏世界构建）
从编辑器到物理、动画，亲手搭建会“动”的游戏世界！
  • 🎮 2.1 Unity 入门 → 🌱 熟悉编辑器操作，能创建基本场景并控制物体移动旋转。
  • 🎮 2.2 Unity 基础 → 🏗️ 掌握物理系统（刚体、碰撞器）、预制体、父子物体，能制作简单的跑酷或弹球游戏。
  • 🎮 2.3 Unity 核心 → 🎯 深入生命周期、动画系统（Animator）、协程、射线检测，能实现第三人称控制和攻击判定。
🎨 第三阶段：UI 系统与数据持久化（交互与存档）
让玩家看得见、摸得着，还能随时存档重来！
  • 🖥️ 3.1 IMGUI → 🛠️ 了解旧版UI原理，能制作简单的编辑器调试面板。
  • 🖥️ 3.2 NGUI → 📦 掌握主流第三方UI插件（老旧项目维护必备）。
  • 🎨 3.3 UGUI → 🔥 （重点） 掌握Canvas、锚点、ScrollView、Button等，能制作商城、血条、聊天框等所有游戏内UI。
  • 🎨 3.4 FairyGUI → ✨ 掌握高级UI方案，能实现复杂的动效UI和图文混排（手游项目常用）。
  • 💾 3.5 PlayerPrefs → 💾 学会存储玩家设置（音量、画质）和简单存档。
  • 💾 3.6 XML → 📂 能用配置文件管理游戏静态数据（如技能表、怪物属性表）。
  • 💾 3.7 Json → 🌐 掌握最主流的数据交互格式，能序列化/反序列化复杂对象（存档+网络传输）。
  • 💾 3.8 二进制 → 🔒 学会加密存储关键数据，防止玩家轻易修改存档文件。
⚡ 第四阶段：进阶功能模块（项目提效与优化）
让游戏跑得更快、适配更多设备，资源管理不再头疼！
  • ⚡ 4.1 C# 知识补充 → 🧩 补全项目中常用的高级C#技巧（如扩展方法、对象池原理）。
  • ⚡ 4.2 TextMeshPro → ✍️ 让游戏文字更清晰美观，支持富文本和表情，是UI文字的“终极解决方案”。
  • ⚡ 4.3 InputSystem → 🎮 适配PC（键鼠）、移动端（触屏）、主机（手柄）等多种输入，实现灵活控制映射。
  • ⚡ 4.4 Addressables → 📦 实现资源的远程加载与热更新分包，有效减少首包体大小。
  • ⚡ 4.5 视频播放 → 🎬 在游戏中植入开场动画、过场CG或广告视频。
  • ⚡ 4.6 ScriptableObject → 🗂️ 用数据资产分离配置与逻辑，方便策划/美术直接调整数值。
  • ⚡ 4.7 性能优化 → 🚀 掌握DrawCall合批、LOD、资源卸载、GC优化，让游戏稳定60帧。
🧩 第五阶段：框架与设计模式（架构师思维）
告别“屎山”，写出能让队友点赞的优雅代码！
  • 🧩 5.1 Unity 程序基础框架（重置版） → 🏛️ 搭建单例模式、事件中心、资源管理、音频管理、UI管理的完整项目底层架构。
  • 🧩 5.2 Unity 中的 MVC 思想（框架） → 📊 将数据显示（Model）、界面（View）、逻辑（Controller）分离，多人协作不再冲突。
🔄 第六阶段：热更新与网络通信（商业项目必备）
不发新包就能修Bug、加玩法，还能让玩家联机互动！
  • 🔄 6.1 Unity 中 Lua 热更新解决方案 → 📜 用XLua/SLua将战斗逻辑、活动配置写在Lua中，实现逻辑代码热修复。
  • 🔄 6.2 热更新中 AB 包的上传下载 → ⬆️⬇️ 配合Addressables/AssetBundle，实现资源从服务器下载并动态加载。
  • 🔄 6.3 Unity 中 ILRuntime 热更新解决方案 → 💻 掌握基于C#的解释器热更（不用学Lua，适合纯C#团队）。
  • 🌐 6.4 Unity 网络开发基础 → 📡 掌握Socket/TCP/UDP基础，能实现简单的多人聊天室或同步位置信息。
🛠️ 第七阶段：编辑器扩展与移动平台（工具链与出包）
写工具让开发效率翻倍，一键发布到手机！
  • 🛠️ 7.1 Unity 编辑器开发之编辑器拓展 → 🔧 自制菜单项、Inspector面板、编辑器窗口，批量处理预制体，提升团队效率。
  • 📱 7.2 Unity 移动平台相关 - Android → 🤖 掌握Android打包流程、权限配置、导出APK/AAB，接入第三方SDK。
  • 📱 7.3 Unity_Jenkins 打包 - iOS 打钉通知 → 🔔 搭建自动化打包服务器，集成钉钉/飞书通知，实现持续集成（CI）。
✨ 第八阶段：图形渲染与特效（视觉表现）
让你的游戏拥有“大片级”画质，不再依赖商店资源！
  • ✨ 8.1 Unity Shader 开发入门 → 🎆 掌握顶点/片元着色器、基础光照模型，能实现边缘发光、菲涅尔效果、UI特效等。
🧭 第九阶段：算法与经典功能实现（攻坚专项）
啃下硬骨头，RTS阵型、精准跳跃、智能寻路全拿下！
  • 🧭 9.1 A 星寻路算法理论基础 → 🗺️ 掌握网格寻路原理，实现怪物自动追踪或RTS单位导航。
  • ⚔️ 9.2 Unity 实现即时战略游戏阵型功能 → 🎯 实现框选单位、扇形/圆形阵型排列与移动（如《星际争霸》）。
  • ⚔️ 9.3 Unity 中实现平台跳跃功能（不使用物理系统） → 🦘 手写碰撞检测与重力模拟，制作手感极佳的2D/3D跳跃机制。
⚔️ 第十阶段：大型实战项目（作品集打造）
把前面学的所有技能融会贯通，产出能写进简历的完整作品！
  • ⚔️ 10.1 Unity 游戏开发之 ARPG 项目 → 🏹 完整实现类《暗黑破坏神》的视角、技能、怪物掉落与装备系统。
  • ⚔️ 10.2 Unity 游戏开发直播回顾（2D 横版动作游戏） → 🗡️ 实现类《空洞骑士》的连击、跳跃、二段跳与关卡设计。
  • ⚔️ 10.3 Unity 游戏开发直播回顾（怪猎 A 实现） → 🐉 实现类《怪物猎人》的弱点打击、肉质反馈与大型Boss战逻辑。
  • 🎒 10.4 基于 UGUI 的背包商店装备 → 🎒 实现物品拖拽、移动、装备更换、售卖购买等完整交互逻辑。
  • 🎒 10.5 Unity 背包里装 10v 个道具 → 📊 重点解决大量物品（10万+）的数据结构优化与UI虚拟滚动性能。
