MessagePack-CSharp - 二进制

小游戏网络通信二进制方案

语雀原稿为空本页内容为补充整理
本模块可运行验证纯 C# · 无需 Unity · 点右下按钮真实编译执行
C#
// MessagePack：二进制体积与编码过程
using System;
using MessagePack;

[MessagePackObject]
public class Move
{
    [Key(0)] public int PlayerId { get; set; }
    [Key(1)] public float X { get; set; }
    [Key(2)] public float Y { get; set; }
    [Key(3)] public string Anim { get; set; }
}

public static class Program
{
    public static void Main()
    {
        var m = new Move { PlayerId = 1001, X = 12.5f, Y = -3.25f, Anim = "run" };

        var bin = MessagePackSerializer.Serialize(m);
        var hex = BitConverter.ToString(bin).Replace("-", " ");
        Console.WriteLine($"对象: PlayerId={m.PlayerId} X={m.X} Y={m.Y} Anim={m.Anim}");
        Console.WriteLine($"MessagePack 体积: {bin.Length} 字节");
        Console.WriteLine($"字节流: {hex}");

        var jsonStr = $"{{\"PlayerId\":{m.PlayerId},\"X\":{m.X},\"Y\":{m.Y},\"Anim\":\"{m.Anim}\"}}";
        var jsonLen = System.Text.Encoding.UTF8.GetByteCount(jsonStr);
        Console.WriteLine($"等价 JSON 体积: {jsonLen} 字节   （省下 {100 - bin.Length * 100 / jsonLen}%）");

        Console.WriteLine();
        var back = MessagePackSerializer.Deserialize<Move>(bin);
        Console.WriteLine($"反序列化: PlayerId={back.PlayerId} X={back.X} Y={back.Y} Anim={back.Anim}");

        Console.WriteLine();
        Console.WriteLine("为什么字段顺序要显式写 [Key(n)]：");
        Console.WriteLine("  二进制不带字段名，只靠 Key 顺序对应。改字段名不影响，改 Key 顺序一定解析错。");
    }
}

接入方式

Unity 里通过 UPM 或 NuGetForUnity 安装 MessagePack。关键是必须生成 Resolver：IL2CPP 下反射被裁剪，不生成 resolver 就会出现「编辑器能跑、真机报找不到 formatter」。

// 菜单：MessagePack > CodeGenerator > GeneratedResolver（或在 Player Settings 里开）
// 纯手工写法：给每个需要序列化的类加 [MessagePackObject] + [Key(n)]

[MessagePackObject]
public class MoveReq
{
    [Key(0)] public int PlayerId { get; set; }
    [Key(1)] public float X { get; set; }
    [Key(2)] public float Y { get; set; }
    [Key(3)] public string Anim { get; set; }
}

var bytes = MessagePackSerializer.Serialize(req);
var back  = MessagePackSerializer.Deserialize<MoveReq>(bytes);
// 压缩版（体积更小，CPU 略高）
var lz4 = MessagePackSerializer.Serialize(req, MessagePackSerializerOptions.Standard.WithCompression(MessagePackCompression.Lz4Block));

什么时候该用它

格式体积可读性适用
JSON大（字段名重复）人可读，好调试存档、配置、调试协议
MessagePack约为 JSON 的 40%~70%需工具查看网络同步、频繁上报
Protobuf最小需 .proto 与代码生成大项目、跨语言、强 schema 约束

踩坑清单

  • Key 顺序不能乱改：二进制里没有字段名，只靠 Key 对应，改顺序就是数据错位。
  • 版本兼容：新增字段用新的 Key，客户端遇到未知 Key 应跳过而不是报错。
  • 不支持的类型：Unity 的 Vector3、Color 需要自己写 Formatter 或转成三个 float。
  • 空值：string 为 null 与 "" 在二进制里不同，协议层要约定死。
