## 公式是怎么转过来的

| 来源 | 处理方式 |
|---|---|
| Word 原生公式（77 个 OMML） | 自写 OMML → LaTeX 转换器，覆盖分式、上下标、根式、求和、函数名、上括号、矩阵等节点 |
| 图片公式（5 张 PNG / JPEG） | 逐张识读后用 LaTeX 矢量重写（标准离差、内含增长率 ×2、可持续增长率 ×2、两阶段增长时间轴、内插法三角形） |
| 正文 | 按 **章 → 节 → 公式** 重新归并，合并碎片标题、去重复关系式、补全符号含义 |

## 页面能力

- **章节导航**：左侧固定栏，滚动联动，当前章自动展开子节
- **全文搜索**：`⌘K` / `Ctrl+K` 聚焦，输入「年金」「杠杆」「存货」即时过滤并显示命中数
- **复制源码**：每张卡片右上角一键复制该公式的 LaTeX
- **打印 / 存 PDF**：A4 分页样式单独适配，卡片不跨页；顶栏按钮直接调用浏览器打印
- **移动端**：抽屉式目录 + 单栏卡片，公式区可横向滚动不撑破页面
- **离线可用**：KaTeX 已预渲染为静态 HTML，字体以 data URI 内嵌，断网甚至禁用脚本都不会掉版

## 原文勘误

页面附录中已同步列出，三处为准：

1. **总杠杆系数**：原文「总杠杆系数 = 经营杠杆系数 × 经营杠杆系数」系笔误 → 应为 `DTL = DOL × DFL`
2. **WACC 与 IRR**：原文两处「加权平均资本成本 > 内含报酬率，方案可行」方向写反 → 标准口径为 **IRR > WACC 才可行**
3. **普通股资本成本**：增长率应在括号外 → `Ks = D₁ / [P₀(1−f)] + g`

另：原文个别小标题存在录入碎片（如「盈利能力比率总纸总总」），已按语义归并。
