# 王道 408 四本教材（合订阅读）

数据结构 / 计算机网络 / 操作系统 / 计算机组成原理，四本 2027 版王道复习指导装进一个页面，顶部选卡切换。

入口：`index.html`

## 为什么是「整页图像」而不是文字

四本 PDF 都是**扫描件，没有文字层**——抽样任意一页 `get_text()` 返回 0 字符。要转成文字只能靠 OCR，而 OCR 会在选项、公式、图表下标处出错，对 408 这种题型是致命的。

所以正文一律用**原始页面图像，一页不少**；OCR 结果只用于全文检索定位，不参与展示。这样既保证「不漏内容」，也不会把错的字塞进你眼前。

## 几个和别人不一样的设定

**页码用书上印的数字。** 四本书的 PDF 页序都比印刷页码大 12（`书内页码 = PDF 页序 − 12`，由每页页眉 OCR 投票校准）。界面全部显示印刷页码，跳转框直接填书上的数，`#cn/138` 也是印刷页。

**卷首单独拆开。** 封面 / 前言 / 致读者 / 王道训练营（广告页）/ 目录各自成条，没有印刷页码的显示 `卷首 pN`（N 为 PDF 页序）。深链写成 `#cn/z5` 这种 `z` 前缀形式，收藏后能准确回到卷首某页。

**目录还原到四级。** 原始书签 478 / 419 / 435 / 485 条，剔掉广告页与重复项后成 468 / 411 / 435 / 479 个节点，共 1793 个。父节点的末页取「自身末页」与「全部子条目末页」的较大值，否则会出现子条目页码超出父节范围。

## 操作

| 动作 | 方式 |
|---|---|
| 切科目 | 顶栏四个选卡 |
| 跳章/节 | 左侧目录点标题；点三角只展开不跳 |
| 跳页 | 右上输入框填**书上印的页码**，回车 |
| 全文搜索 | 左侧输入框切「全文」，跨四本书一起搜，结果按书分组 |
| 翻屏 / 翻节 | `←` `→` / `[` `]` |
| 聚焦搜索 | `/` |
| 深链 | `#cn/138`（计网第 138 页）、`#co/z5`（组成原理卷首第 5 页）、`#q=分片`（搜索结果） |
| 夜间模式 | 右上角月亮按钮 |

每本书的阅读位置存在本机 localStorage，回到页面会接着上次的位置。

## 重建

```bash
cd build
python3 make_toc.py      # 清洗书签 → toc.json
python3 export_pages.py  # 导出页面图（132dpi / WebP q76）
python3 ocr_index.py     # 生成 search/*.js
python3 detect_offsets.py# 用页眉 OCR 校准页码偏移
python3 make_site.py     # 生成 index.html
```

重建需要四个原始 PDF 在同级目录的上一级，且已装 PyMuPDF、Pillow、tesseract（含 `chi_sim`）。
