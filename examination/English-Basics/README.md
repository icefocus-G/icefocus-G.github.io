## 使用提示

- 顶栏选项卡可点，也可用 `←` `→` 方向键切换；停留位置记在 localStorage，下次打开回到上次的选项卡。
- 各选项卡内左侧有本模块目录，手机端收成限高卡片。
- 01 语法页的「紧凑模式」按钮会全局压缩行距，适合快速翻阅。
- 纯静态页面，可直接浏览器「打印 / 存 PDF」，打印时只输出当前选项卡。
