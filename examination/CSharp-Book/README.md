# C# 语言图谱（原 C# 交互课件）

语雀《C# 学习》知识库 11 篇原稿 → 按 6 个分类 / 11 个模块重组，用图谱式外壳呈现：
**左侧模块卡导航 + 顶部面包屑 + 精读 / 代码 / 图示 三页签**。

## 怎么打开

双击 `index.html`，或用任意静态服务器打开本目录。首页是总览仪表盘（KPI + 分类筛选 + 11 张模块卡 + 排序演示），
点卡片进入模块页；模块页顶部的三页签：

| 页签 | 内容 | 交互 |
|---|---|---|
| 精读 | 语雀原稿逐块还原（一字未改）+ 该模块的图形演示 | 演示可点、可拖、可播放 |
| 代码 | 本模块全部代码段，按出现顺序排列并标注所在小节 | 单段复制 |
| 图示 | 本模块全部配图 | 点击放大（Esc 关闭） |

左侧模块卡实时显示阅读进度；每篇文章底部有「标记已读」，进度存 localStorage。

## 目录结构

```
CSharp-Book/
├── index.html           总览仪表盘（分类筛选 + 模块卡 + 排序演示）
├── m01.html … m11.html  11 个模块页（精读 / 代码 / 图示）
├── assets/
│   ├── atlas.css        图谱外壳（配色、侧栏、页签、正文排版）
│   ├── atlas.js         页签切换、代码抽取、图示灯箱、搜索、阅读进度
│   ├── anim.css         13 个图形演示的样式
│   ├── anim.js          13 个图形演示（rAF 驱动，Canvas / SVG / DOM）
│   ├── img/             26 张配图（已从语雀 CDN 本地化）
├── build.py             原稿 → 旧版 HTML（语雀 md 渲染器，保留不动）
├── gen_atlas.py         旧版 HTML → 图谱外壳（抽取演示区/正文，重排导航与页签）
├── pairs.json           07 对照表抽出的 48 组词条，供翻卡演示
├── course.json          课程中心配置（order 6，theme #68217a）
├── README.md
└── 原稿/                11 篇语雀 md 原件
```

> 原 `assets/style.css` 与 `assets/app.js` 已由 `atlas.css` / `atlas.js` 取代，不再被引用。

## 两层构建

```
原稿/*.md  --build.py-->  m01..m11.html（旧版：顶栏 + 侧栏目录 + 正文）
                          ↓
                       gen_atlas.py（抽取 演示区 / 正文 → 套图谱外壳）
                          ↓
                       m01..m11.html（新版：模块卡 + 三页签）
```

改正文请改 `原稿/*.md`，然后依次跑：

```bash
python3 build.py        # 生成旧版正文（脚本顶部 SRC 指向原稿目录）
python3 gen_atlas.py    # 重排成图谱外壳
```

只调样式/交互改 `assets/atlas.css` 与 `assets/atlas.js` 即可，不必重跑构建。
