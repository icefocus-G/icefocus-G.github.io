💡04构造函数，析构函数,垃圾回收

构造函数

1 实例化对象 的时候 会调用构造函数

2.类有默认的无参构造函数，如果不声明无参构造函数，会被其他有参构造函数顶掉

3.构造函数用户初始化 可以:this(）先调用其他的函数，再执行构造函数

4.一般为 public

C#

GC 垃圾回收机制 //每此内存释放都会损耗性能，会导致程序卡顿 //垃圾回收一般在游戏进度条使用

C#中 栈上系统自动执行， heap 堆上需要手动释放

0 代内存 内存满了，会自动释放，

01 从根部开始查找，内存中 哪些变量是没有被引用的（没有从栈上指引到堆上内存地址），

02 然后搬迁可达对象（有引用的）的的放入 2 代内存，并进行压缩随机排序

03 然后修改引用地址进行顺序排序

1 代内存 满了的时候， 0,1 代的内存 一起释放

01，然后搬迁可达对象 放入第 2 代内存，

2 代内存 满了的时候， 0,1 ，2 代的内存 一起释放

大对象一般存在 2 代内存（减少性能损耗，提高性能），不会进行内存压缩 （83KB 以上的对象为大对象）

02 索引器 结合 数组 的使用（数组进行自动扩容 和 删除元素）

C#
class IntArray {
//自定义一个整形数组类
    int capacity;//数组容量
    int length;//数组长度

    private int[] array;

    #region  增加
   public IntArray()//用构造函数堆数字进行初始化
   {
        capacity = 5;
        length = 0;
        array = new int[capacity];

    }
    public void Add(int value)//数组自动扩容方法
    {

        if (length < capacity)//当长度小于容量时候，
        {
            array[length] = value;//直接增加元素

            ++length;//长度增加

        }
      
        else//当长度大于容量时候
        {
            capacity = capacity * 2;  //容量进行翻倍

            int[] tempArray = new int[capacity];//声明临时工数组
            for (int i = 0; i < array.Length; i++)//进行数组遍历搬家
            {
                tempArray[i] = array[i];

            }
            array = tempArray;//重新array指向新的堆内存引用地址
            array[length] = value;//增加元素
            ++length;//长度增加

        }

      
    
    }

    #endregion

    #region 删除
    public void Remove(int value)//删除数组对应位置的值
    { 

        for (int i = 0; i<length; i++)
        {

            if (array[i] == value) //遍历数组 找到输入的值
            { 
               RemoveIndex(i);//执行移除对应值对应索引的方法
               return;//结束方法
            }
       
        }
        Console.WriteLine("你输入的{0}在数组中不存在", value);

    }
    public void RemoveIndex(int index)//删除数组对应位置的索引位置
    { 

        if(index>length)
        {
            
            Console.WriteLine("越界了,当前长度是{0}",length);
            return;
        }
        for (int i=index;i< length - 1;i++)
            //Lenght-1 因为传入索引值后的元素都往前面移动了，所以最后的位置可以不进行遍历
        {
            //将输入的索引位置后进行遍历
            //然后让后面的位置都往前面移一个位置
            array[i] = array[i+1];
        
        
        }
        --length;//因为传入索引值后的元素都往前面移动了 ，数组长度-1



    }


    #endregion

    #region  查 改

    public int this[int index]
    {
            get
            {
                if( index >= length || index < 0)
                {
                    Console.WriteLine("越界");
                    return 0;
                }
                return array[index];
            }
            set
            {
                if (index >= length || index < 0)
                {
                    Console.WriteLine("越界");
                }
                array[index] = value;
            }
    }

    #endregion

   

}

//索引器的使用
internal class Program
{

        array.Add(344);
        array.Add(144);
        //数组元素移除后，后面元素都往前进一个位置
        Console.WriteLine("移除array[1]之前的位置值是{0}", array[1]);//通过索引器进行查
        array.RemoveIndex(1);
        Console.WriteLine("移除array[1]后的索引的值是{0}",array[1]);
        //移除array[1]  144 后  array[1]为 344

💡07静态成员

C#
static 静态成员 不需要类实例化，就可以通过类名点出来。

程序使不能无中生有的，我们要使用的对象，变量，函数都是要在内存中分配内存空间的，要实例化对象的目的就是要分配内存空间，在程序中产生一个抽象的对象。

静态函数中不能使用非静态成员 （因为静态函数是程序开始时候就分配了内存空间的，非静态的成员没有分配空间，无法调用）

（ 如果要使用，可以实例化一个类，然后分配了类的内存空间后，直接调用类中的成员）

非静态函数可以调用静态成员（静态成员程序初已 分配了内存空间，然后非静态函数要使用需要实例化对象，也会分配内存空间）

1.在程序生命开始就会 为静态成员专门的静态存储区域 分配 内存空间，直到程序生命结束 才会释放内存，

2.每个静态成员在程序中具有唯一的内存空间， 使每一个静态成员具有唯一性

3.在任何地方都是可以使用静态成员的内容，改变静态成员中的内容，其他地方也会跟着改变

4.静态一般用于相同规则的数学计算相关函数，尽量少用，会占用内存空间，降低性能

5.静态函数可以使用静态变量（因为程序初 都 在内存分配了空间）

6.静态函数 不能 使用 非静态变量（因为非静态变量没有实例化，需要实例化在内存中分配空间后，才能被使用）

7.const 常量可以理解为特殊的静态 （const 只能修饰变量，必须初始化，可以通过类名 点出来 ，必须写在访问修饰符后面 ）

静态变量的优点 1.全局性，2 唯一性。 缺点 静态成员太多 会造成程序卡顿。

C#

{

   public const pi=3.14;
   static public int a;

💡08 静态类和静态构造函数

1.静态类 封装 常用的 静态成员 （不能有非静态成员）方便使用

2.静态类 不能被实例化，更能体现工具类的 唯一性，静态类可以实现拓展方法

3.Console 就是一个静态类

💡04string builder 解决 string 缺陷

可以自动扩容的大容量字符数组

C#
string 是特殊的引用，每次重新赋值或者拼接的时候会分配新的内存空间，字符串经常改变会造成性能消耗
C#
string builder 本质是一个字符数组，另一种封装形式

C#提供的一个用于处理字符串的公共类

解决：修改字符串二不创建新的对象，需要频繁的修改和拼接字符串可以使用它，

C#
提高性能，使用前需要引用命名空间 using System.Text;

使用：必须实例化

C#
StringBuilder str=new StringBuilder("双缝干涉三国杀");

StringBuilder str=new StringBuilder("双缝干涉三国杀",100);//可以初始化的时候分配指定的大小（最大 100 ）个位置

容量：StringBuilder (）每次往里面增加时 会自动扩容

初始容量 16 个位置，每次扩容会 X2

长度 ，实际存储的字符串长度

C#
using System.Text;
    

internal class Program
    {
        static void Main(string[] args)
        {
           StringBuilder str=new StringBuilder("双缝干涉三国杀");
           str=str.Append("44444");//增加字符串内容，从string builder 未使用空间增加，如果超过长度会自动扩容
            
           str.length //字符串长度
           str.Capacity //字符串容量
           str.AppendFormat("{0}{1}",100,9);//字符串拼接
           str.Insert(0,"XXX")//从 0位 开始 插入XXX内容
           str.Remove(0,10);//从0位开始删除10个位置
            str.Clear();//直接清空
            str[2];//直接通过StringBuilder中的索引器 下标 查
            str[2]='A';StringBuilder可以通过下标直接修改，string中是不能的
            str.Replace("原","新");//StringBuilder不会产生新字符，会直接改变原字符串内容
            
        }
C#
StringBuilder 要重新赋值 ，必须 str.Clear()；清空后 进行 增加 str.Append("时光飞逝贵公司撒");

💡06 结构体和类的区别

TEXT
region 区别概述
            //结构体和类最大的区别是在存储空间上的，因为结构体是值，类是引用，
            //因此他们的存储位置一个在栈上，一个在堆上，
            //通过之前知识点的学习，我相信你能够从此处看出他们在使用的区别——值和引用对象在赋值时的区别。

            //结构体和类在使用上很类似，结构体甚至可以用面向对象的思想来形容一类对象。
            //结构体具备着面向对象思想中封装的特性，但是它不具备继承和多态的特性，因此大大减少了它的使用频率。
            //由于结构体不具备继承的特性，所以它不能够使用protected保护访问修饰符。
            #endregion

            #region 细节区别
            //1.结构体是值类型，类是引用类型
            //2.结构体存在栈中，类存在堆中
            //3.结构体成员不能使用protected访问修饰符，而类可以
            //4.结构体成员变量申明不能指定初始值，而类可以
            //5.结构体不能申明无参的构造函数，而类可以
            //6.结构体申明有参构造函数后，无参构造不会被顶掉
            //7.结构体不能申明析构函数，而类可以
            //8.结构体不能被继承，而类可以
            //9.结构体需要在构造函数中初始化所有成员变量，而类随意
            //10.结构体不能被静态static修饰（不存在静态结构体），而类可以
            //11.结构体不能在自己内部申明和自已一样的结构体变量，而类可以
            #endregion

            #region 结构体的特别之处
            //结构体可以继承 接口 因为接口是行为的抽象
            #endregion

            #region 如何选择结构体和类
            //1.想要用继承和多态时，直接淘汰结构体，比如玩家、怪物等等
            //2.对象是数据集合时，优先考虑结构体，比如位置、坐标等等
            //3.从值类型和引用类型赋值时的区别上去考虑，比如经常被赋值传递的对象，并且
            //改变赋值对象，原对象不想跟着变化时，就用结构体。比如坐标、向量、旋转等等
            #endregion
        }

💡07 抽象类和接口的区别

C#
 #region 知识回顾
            //抽象类和抽象方法
            //abstract修饰的类和方法
            //抽象类 不能实例化
            //抽象方法只能在抽象类中申明 是个纯虚方法 必须在子类中实现

            //接口
            //interface 自定义类型
            //是行为的抽象
            //不包含成员变量
            //仅包含方法、属性、索引器、事件，成员都不能实现，建议不写访问修饰符，默认public
            #endregion

            #region 知识点一 相同点
            //1.都可以被继承
            //2.都不能直接实例化
            //3.都可以包含方法申明
            //4.子类必须实现未实现的方法
            //5.都遵循里氏替换原则
            #endregion

            #region 知识点二 区别
            //1.抽象类中可以有构造函数；接口中不能
            //2.抽象类只能被单一继承；接口可以被继承多个
            //3.抽象类中可以有成员变量；接口中不能
            //4.抽象类中可以申明成员方法，虚方法，抽象方法，静态方法；接口中只能申明没有实现的抽象方法
            //5.抽象类方法可以使用访问修饰符；接口中建议不写，默认public
            #endregion

            #region 如何选择抽象类和接口
            //表示对象的用抽象类，表示行为拓展的用接口
            //不同对象拥有的共同行为，我们往往可以使用接口来实现
            //举个例子：
            //动物是一类对象，我们自然会选择抽象类；而飞翔是一个行为，我们自然会选择接口。
            #endregion
