至此，我们已经讨论了从 (行)·(列) (点积) 以及 (矩阵)·(列) 两个角度来理解 AB. 另外还有两种方法 (行)·(矩阵) 以及 (列)·(行). 这四种方法也都需要 mnp 次乘法运算，只是运算次序不同. 如果 A 和 B 都为 2 × 2 矩阵，那么需要 n3 = 8 次运算来得到 AB.①

1.4.1通常来说 AB ≠ BA

对 B=[01​10​]，AB 为互换 A 的两列得到的矩阵，而 BA 是互换了 A 的两行得到的矩阵！

AB=[24​13​]BA=[01​10​][13​24​]=[31​42​] (1.18)

这个简单的例子就说明了，通常矩阵的乘积运算不是可交换的：BA ≠ AB. 在 A 的左边乘 B 是对 A 的行进行操作，而在右边乘 B 是对 A 的列进行操作.

问题. 为什么将对换矩阵平方得到单位矩阵：B2=[01​10​][01​10​]=I？

1.4.2(AB)C = A(BC)

矩阵乘法的结合律成立. 结合律非常有用，若非万不得已，我们都希望保留这个运算规则. 我们可以先计算 AB，也可以先计算 BC.

这里 A、B、C 的顺序是保持不变的，所以它们的大小应该满足矩阵乘法的运算要求：

A 为 m×n 矩阵，B 为 n×p 矩阵，C 为 p×q 矩阵，AB 为 m×p 矩阵，(AB)C 为 m×q 矩阵.

我们可以用对换矩阵 B 对矩阵 A 的行和列的影响来检验结合律：

(BA)B=([01​10​][13​24​])[01​10​]=[31​42​][01​10​]=[42​31​]
B(AB)=[01​10​]([13​24​][01​10​])=[01​10​][24​13​]=[42​31​]

这就是说，对 A，无论是先作行变换再作列变换，还是先作列变换再作行变换，结果是不变的.

特别需要说明，当 C 仅仅是一个列向量 x 时，(AB)C = A(BC) 的意义. 如果 x 只在第 j 个分量是 1，其他分量是 0，根据结合律有 (AB)x = A(Bx). 这就告诉了我们应该如何计算矩阵的乘法：等式左边为 AB 的第 j 列，等式右边为 A 乘以 B 的第 j 列. 所以这一等式正是前面式(1.13)给出的矩阵乘法的定义.

现在，我们总结关于 ABC 以及 A 乘以 B + C 的重要的运算规则：

结合律(AB)C=A(BC)分配律A(B+C)=AB+AC (1.19)
①作者注：Strassen 发现对于 2 × 2 矩阵的情况，7 次乘法运算就已经足够得到 AB，代价是额外的 1 次加法. 对于 n × n 矩阵，乘法的计算量为 nc，其中 c=log2​7，而不是通常认为的 c=log2​8=3. 现在 c 可以降得更低. 当然 c 不可能小于 2，因为 A 和 B 都有 n2 个元素. 寻找最小的 c 仍然是一个非常难的公开问题.
