# 线性代数 · Strang 第 6 版 · 两个页面

Gilbert Strang《线性代数》原书第 6 版（刘余、黄晔辉、杨晶 译 · 清华大学出版社）。
同一个目录里放了两套读法，互相链接：

| 文件 | 是什么 | 适合 |
| --- | --- | --- |
| **`index.html`** | **原书页版（主入口）**：438 页扫描原样呈现，在每节对应位置插入交互实验与自测 | 想「照着书读」，要原书排版、原书颜色、原书顺序 |
| `图解版.html` | 图解精讲版：按原书目录重写的 186 个知识点，配 34 个拖拽实验 | 想「先看懂」，看公式卡片、结论提炼、逐节推导 |

两页顶部互相有入口，侧栏都能跳 47 节，阅读进度共用（同一 `localStorage` 键）。

## 一、原书页版 `index.html`

### 怎么打开

1. **双击 `index.html`** —— 讲解、438 页页图、34 个实验、40 组自测全部可用（页图是本地 `assets/pages/`，`file://` 下正常显示）。
2. **双击 `启动服务器.command`** —— 起本地服务（默认 `http://127.0.0.1:8790`）。阅读进度写 `localStorage`，个别浏览器在 `file://` 下会禁用，走 http 更稳。
3. 手动：本目录 `python3 server.py`。

> 搬动时**整个目录一起拷**（`index.html` + `assets/`）。页图 438 张约 40 MB，是外链不是内嵌。

### 为什么是「页图」而不是重排文字

这本 PDF 是**纯扫描件**：438 页、每页一张 1234×1535 位图，`get_text()` 全空，没有文字层。
所以「保留原书结构 / 排版 / 颜色区别」唯一忠实的做法，就是把原书页原样铺上来——

- **结构与顺序**：卷首 24 页 → 第 1–10 章（按原书页码切分，每节一个 `<h3>`，标出 `p.A–B`）→ 附录 A（p.396–414）。
- **排版**：扫描原图，字号层级、公式编号 `(10.4)` 的位置、脚注、双栏习题，全部原样。
- **颜色区别**：原书的蓝色小节标题、蓝色公式编号、蓝底重点框（如 p.303「7.2 通过线性代数来做图像处理」的浅蓝结论框）都在图里，没有被二次排版洗掉。
- **页序换算**：PDF 下标 = 印刷页码 + 23（`PDF[110]` 页眉是 `87`）；文件名 `p%04d` 是 1 基，所以 `printed = 文件名 - 24`。

### 页面上叠加了什么

| 位置 | 内容 |
| --- | --- |
| 每节标题下 | `1.2 点积、长度和角度　p.9–18`，与侧栏、原书目录一致 |
| 本节页图之后 | **动手 · 本节 N 个交互实验**（含滑块 / 可拖点 / 实时读数） |
| 实验之后 | **检验 · 本节自测**（对应原书习题 X.Y，2 道题 + 答案，折叠） |
| 节末 | 「本节图解精讲 →」跳到 `图解版.html#sX_Y` |
| 点页图 | 灯箱放大，`←` / `→` 或按钮翻页，`Esc` 关闭 |
| 侧栏 | 章 → 47 节；搜索过滤；已读打勾；底部进度条 + 清零 |

尺寸：`index.html` 336 KB（正文与脚本内嵌），`assets/pages/` 438 张 WebP 共 40 MB（1000px 宽 · q76 · 保留原色，懒加载）。

## 二、图解精讲版 `图解版.html`

按原书完整三级目录重写的可交互课本，视觉与交互沿用「② 线性代数 · 从 0 到学会（可交互图解版）」的 SVG 可拖拽平面引擎与配色体系，内容深度对齐「③ 0 基础到精通 交互版」。

**规模：10 章 · 47 节 · 186 个三级知识点 · 40 组习题（80 道自测）· 34 个可交互实验（其中 21 个可直接拖图里的点）· 45 张原书插图 · 182 个公式块。**

| 功能 | 说明 |
| --- | --- |
| 左侧三级目录 | 章 → 节 → 知识点，随滚动高亮 |
| 搜索框 | 实时过滤 47 个节标题 |
| 阅读进度 | 看过的节变淡，底部「已读 x / 47 节」 |
| 拖拽实验 | 滑块 + 实时读数；**21 个实验的图形里直接有可拖点**（见下表） |
| 实验 1.1 / 1.2 / 1.3 | 拖向量 `v` / `w` 的尖端，看线性组合、点积投影、列空间跟着变 |
| 实验 3.1（子空间） | **拖直线上的点上下移截距**，跨过 0 的瞬间「是子空间 → 不是子空间」翻转 |
| 实验 4.2 / 4.3 / 4.5 | 拖 `b` 看投影落点；拖散点看最小二乘直线重拟合；拖向量看广义逆 |
| 实验 6.3（正定） | **拖橙色 (b, c) 落点 = 改矩阵 A 的第二列**；往下拖过 c = b² 就翻成「不定 / 鞍点」 |
| 实验 6.5（相图） | **拖紫色初值点**，加粗的轨迹立刻重算；λ₁、λ₂ 仍可拖滑杆 |
| 实验 7.1（SVD 几何） | **拖 Ae₁ 蓝点 = 改矩阵第一列**，椭圆跟着变形；拖到与 Ae₂ 共线则退化成线段 |
| 实验 7.2（低秩近似） | **直接点 8×8 格子涂改图案**，实时重算 SVD；**点 σ 柱**可切换保留秩 k；另有「重置 / 随机」 |
| 实验 7.3（PCA） | **三个橙点随便拖**，PC1 方向与解释方差实时变 |
| 实验 8.1（线性映射） | 除三个滑块外，**可直接拖图上 Ae₁ / Ae₂ 两个落点**改矩阵 |
| 实验 8.2（基变换） | **拖 m₁ 的紫点转基**（锁在半径 2 的圆上），B 的四个元素实时变而特征值不动 |
| 实验 9.1（梯度下降） | **拖黑色起点**，之字形轨迹与 30 步误差重算 |
| 实验 10.1（折纸） | 拖控制点改分段线性函数 |
| 原书插图 | 45 张扫描插图，图注标原书图号与**印刷页码** |
| 折叠块 | 例题 / 判断（✓✗）/ 简答 / 习题自测 |

## 五、边界（如实说明）

1. **原书是扫描件，没有文字层**：页图不能选中、不能全文检索、不能复制文字。要检索请用 `图解版.html`（正文是重写的，可搜索）。
2. **页图 1000px 宽**：在 860px 版心里阅读清晰；再放大到 100% 会有扫描颗粒感，属原始素材限制。
3. **图解版原文不是逐字复制**：目录、章节顺序、页码、图号与原书严格对应；正文是按目录与标准结论重写的讲解，不是原书文字的转录。
4. **习题只给锚点与自测**：原书习题未逐题抄录（扫描件 + 版权），每节给出「习题 X.Y · 起始页码」+ 2 道覆盖该节考点的自测题。
5. **图注页码已换算为印刷页码**（偏移 24 页），全部落在对应章节区间内。

## 六、这一版修掉的 bug（都在 `build/audit_*.py` 里有对应检查）

| # | 现象 | 原因 | 处理 |
| --- | --- | --- | --- |
| 1 | 原书页**整体错位一页**，卷首第一张是断图 | 文件名 `p0001` 是 1 基，生成器却拿 0 基 PDF 下标当文件名 | `page_fig()` 改用 `idx+1`，并逐节校验 `p.A–B ↔ A+24…B+24` |
| 2 | 封面倒置 | PDF 前 4 页 `/Rotate=180`，取内嵌位图拿到的是未旋转原图 | `render_pages.py` 按 `/Rotate` 补旋转 |
| 3 | **实验 7.2 下方的 σ 柱、数值、图例被切掉**，右图右侧被裁 | 画布 viewBox 只有 560×400，而图元画到 y=430、x=592 | 重排布局（格子 30px、σ 区下移），并把画布改成可涂改 |
| 4 | 实验 3.2 / 4.2 / 5.1 / 10.2 的标签贴到边框外或互相压住 | 文字画在坐标系边界外 / 两个标签同点 | 挪进视野、错开偏移；4.2 默认 b 与 a 重合的问题改为 b=(3,2) |
| 5 | 实验 3.5 / 9.2 / 10.2 文字重叠 | 两段文字 bbox 交叠 | 拆开位置，9.2 的两条梯度箭头改成「实线 + 放大 1.45 倍的虚线」 |
| 6 | 侧栏 46 个节亮着「有实验」小圆点，实际只有 34 个 | `labs_by_section()` 给无实验的节也建了空 key | 只在真正抽到实验时才建 key |
| 7 | 图解版顶部没有返回原书页版的入口 | 两版是分别生成的 | 图解版 hero 加「← 原书页版」 |
| 8 | 实验 **7.3 / 7.1 的提示写着「拖点改变分布」「拖矩阵元素」，实际只有滑杆和按钮** | 文案先写、交互没跟上 | 真给 7.3 加了 3 个可拖橙点、给 7.1 加了可拖 Ae₁；文案与实现对齐 |
