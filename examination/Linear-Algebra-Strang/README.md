## 为什么是页图

这本 PDF 是纯扫描件：438 页、每页一张位图，没有文字层。
所以「保留原书结构 / 排版 / 颜色区别」唯一忠实的做法，是把原书页原样铺上来：

- **结构与顺序**：卷首 24 页 → 第 1–10 章（按原书页码切分，每节一个标题，标出 `p.A–B`）→ 附录 A。
- **排版**：扫描原图，字号层级、公式编号位置、脚注、双栏习题全部原样。
- **颜色区别**：原书的蓝色小节标题、蓝色公式编号、蓝底重点框都在图里。
- **页序换算**：`印刷页码 = 文件名 − 24`（文件名 `p0001` 是 1 基）。

要检索文字请用 `图解版.html`——它的正文是重写的，可以全文搜索。
