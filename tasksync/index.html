把本机任务同步到云端

本机任务存在 WorkBuddy 的数据目录里，需要一台运行采集器的机器把它送上来。

1
在装有 WorkBuddy 的电脑上启动采集器

保持窗口开着，它会监听本机任务的变化。

node collector/collect.js --serve
2
点一下，从本机读取

只有这台电脑的浏览器能读到它，任务不会经过别人。

正在检测…

本机采集器没在运行，所以读不到任务。装一次就好，之后开机自启，你只用点「立即同步」。

在终端里粘贴执行（Terminal.app / iTerm，不是这个网页），或者点「下载」拿到安装文件后双击运行。 装完这里会自动变成可用，不用刷新。

读完先看范围，确认了才上传。

3
没装采集器？直接选目录（免安装）

用 Chrome / Edge 点下面的按钮，在文件框里选中个人文件夹（也就是 ~），或者直接选中 .workbuddy 目录，两种都认。

这条路只读任务正文：浏览器读不了 workbuddy.db，所以会话标题会显示成「会话 xxxxxxxx」，任务也归不到具体 WorkBuddy 账号；产物文件不会上传。应急用，日常还是装采集器。

4
或者导入快照文件

在任意电脑执行 node collect.js 生成 tasks-snapshot.json，拖进来即可。
