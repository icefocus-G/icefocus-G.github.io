# 工具箱（/tool/）

独立页面，预留 20 个工具格子。首页三套皮肤（`ThemedSkin/`）的导航里都已经加了「工具箱」入口。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面本体（样式内联，无外部依赖） |
| `tools.js` | **工具清单**，20 条，只改这个文件 |

## 怎么加一个工具

打开 `tools.js`，找到任意一个 `href: ''` 的空位，把它填满：

```js
{
  id: 'slot-03',
  name: '我的新工具',
  desc: '一句话说明它是干什么的。',
  href: 'https://example.com/',   // 也可以写 ../software/xxx 这种站内相对路径
  tag: '在线',                     // 可选，右上角小标签
  icon: '⌘',                      // 可选，不填就用名称首字
  open: true,                     // 可选，默认 true = 新标签页打开
}
```

保存、提交、推上去就生效。页面上的「N / 20 已启用」和顶部的小圆点会自动更新。

`href` 留空的格子会显示成虚线「待添加」，不会变成死链。

## 为什么用 `.js` 而不是 `.json`

用 `<script src="tools.js">` 载入，直接双击打开本地 `index.html`（`file://`）也能正常显示；
换成 `fetch('tools.json')` 的话，本地打开会被浏览器的同源策略拦掉，只有部署到线上才正常。

## 想改成 30 个格子

`index.html` 里的 `var SLOTS = 20;` 改掉，再在 `tools.js` 里补足对应条目即可（不足会自动补空位）。
